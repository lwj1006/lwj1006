# E/E2 服装全局去重

服装以图集模板 ID 为单位，全人物共享已用记录。任一人物首次成功生成该套的一张图片后，这套服装即锁定；同一次任务按所选张数继续完成。以后换人物、普通启动、选择其他范围或随机池均跳过该套。用完即结束，永不自动清空。

L 续跑保存的未完成队列，不会把普通启动变成新的去重周期。每套 A/全部表示本次获准分配的服装全部图片，不绕过全局服装检查。

兼容旧 `config/used_character_photoset_templates.json`：虽然 JSON 仍保留人物键，选图取所有人物记录的并集，不按当前人物单独判断。单图成功历史可以补回 `__global__` 记录；已有 `clothing_theme_usage_log.jsonl` 中明确的 photoset 成功使用记录也会补回。日志不能确定的单图编号不会臆造。历史格式损坏则停止，不按空历史继续。

原有历史文件均保留，不上传运行时历史和冷却状态。这里按模板 ID 识别同一套服装，不是按图片内容识别不同模板中外观相似的衣服。E/E2 提示词和服装颜色规则不变。
