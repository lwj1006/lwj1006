# 夏日和风浴衣街拍写真｜超详细参考说明

> 用途：作为下一套图的“照片集参考说明 / 图像生成提示词 / 分镜设定”。  
> 核心关键词：**夏日日本小巷、白底果实纹浴衣、湖蓝色腰封、花簪低发髻、西瓜冰棒、风铃、团扇、红色竹编小篮、强日光、浅景深、清爽高调街拍**。

---

## 1. 整体主题定位

这套图的主题是 **“盛夏午后，穿浴衣在日本小巷散步的清爽少女感写真”**。  
氛围不是祭典夜景，而是明亮、安静、空气感很强的白天街拍。画面核心是：浅色浴衣在阳光下微透、湖蓝色腰封形成清凉色块，红色小果实图案和西瓜冰棒形成夏日点缀，背景是窄窄的日式商业街、咖啡店、冰品店、灯笼、风铃、招牌、自行车、遮阳伞。

最终画面要有 **真实写真质感、轻微日系胶片感、柔焦高光、街道纵深虚化、夏天蒸腾感**。人物表情以温柔、轻笑、回眸、眯眼、俏皮为主，不要过度性感，不要舞台感，不要重妆，不要夜景霓虹。

## 2. 人物视觉设定

### 2.1 年龄与气质

- 成年年轻女性气质，清爽、温柔、可爱但不过分幼态。
- 表情干净自然，像夏日出门逛街时被朋友抓拍。
- 气质关键词：**清甜、亲近、日系、夏日、轻盈、温柔、略俏皮**。
- 避免：浓烈网红脸、厚重妆容、过度成熟性感、夸张表情、低龄儿童化比例。

### 2.2 发型

- 发色：自然深棕 / 暖棕黑，不是纯黑，也不是明显染金。
- 发型：低盘发或低发髻，后侧收起，带自然碎发。
- 刘海：轻薄空气刘海，略微中间分散，额前有柔软碎发。
- 两侧有自然垂落发丝，贴近脸颊，增强日系感。
- 头饰位于头部侧后方，偏右侧或后右侧，形成回眸时的视觉亮点。

### 2.3 发饰

- 花簪组合：白色大花 + 淡黄色小花 + 蓝色小花 + 粉红点缀。
- 可有细小垂坠珍珠或白色流苏。
- 花饰不是华丽舞台头冠，而是夏日浴衣用的轻巧和风发饰。
- 颜色需要与浴衣、腰封呼应：**白、奶黄、湖蓝、浅粉**。

### 2.4 妆容

- 底妆清透，高光柔和，皮肤白净但保留自然血色。
- 眼妆：细眼线，清淡卧蚕，睫毛自然纤长。
- 腮红：浅粉、淡桃色，重点在面中与眼下，清甜感。
- 唇色：水润粉桃色，不要浓红，不要暗色。
- 整体是 **夏日淡妆 + 日系写真修图**，不是强烈棚拍妆。

## 3. 服装设定

### 3.1 浴衣主体

- 白色或极浅米白色夏季浴衣。
- 面料轻薄，有细密织纹，阳光下有轻微透光感。
- 图案是清爽果实与植物纹样：
  - 红色小圆果 / 小苹果 / 小樱桃感图案；
  - 绿色叶片；
  - 淡蓝透明圆点或气泡；
  - 少量淡黄色花纹或小兔形 / 夏日图案。
- 袖子宽大、轻盈，动作时呈自然垂坠。
- 衣领干净，不要开得过低；整体保持和风街拍的端庄清爽感。

### 3.2 腰封与背后蝴蝶结

- 腰封为 **湖蓝色 / 青蓝色 / 浅蓝绿色**，是整套图最重要的色块。
- 后背有大蝴蝶结结饰，形状明显，布料厚实但不僵硬。
- 背面拍摄时，腰封结要成为画面焦点之一。
- 可有小西瓜形腰带扣或橙红色小装饰点。

### 3.3 配饰

- 手部可戴细戒指，银色或透明感。
- 耳饰可为白色小花、珍珠流苏、银色小环。
- 手持道具与包袋是重点：
  - 红色竹编小篮；
  - 西瓜图案圆扇；
  - 透明风铃；
  - 西瓜冰棒；
  - Ramune 汽水 / 矿泉水瓶；
  - 小型和风手提包。
- 避免现代大牌 logo、厚重金属饰品、欧美街头饰品。

## 4. 场景设定

### 4.1 主场景：夏日日本小巷

- 窄街道，两边是低层店铺、咖啡店、和风喫茶、冰品店。
- 街道纵深明显，远处强烈虚化。
- 背景可出现：
  - 日式纸灯笼；
  - 冰品旗帜；
  - 咖啡店招牌；
  - 自行车；
  - 路边盆栽；
  - 白色遮阳伞；
  - 店门口木制门面；
  - 小型灯箱招牌。
- 不要过于现代摩天楼，不要赛博霓虹，不要夜祭。
- 画面时间：夏季中午到下午早段，太阳很强，空气发白。

### 4.2 店铺细节

可出现模糊但有氛围的日文招牌，例如：

- コーヒー
- おしるこ
- あんみつ
- ラムネ
- 氷
- 喫茶
- 鈴の木
- BELLE & EMMA

文字只作为背景氛围，不要让 AI 生成一堆乱码大字。招牌可以虚化、边缘化、半遮挡。

### 4.3 光线

- 强烈日光，高调曝光。
- 背景和远处可轻微过曝，形成夏日白亮感。
- 人物脸部仍需保留柔和阴影，不要完全糊成白片。
- 逆光、侧逆光、顶部日光混合。
- 浴衣边缘、头发边缘有轻微发光轮廓。
- 可有树影、店铺遮阳篷影子落在地面或人物袖子上。

### 4.4 景深

- 大光圈浅景深，背景城市街道高度虚化。
- 人物、手持道具、浴衣纹样清晰。
- 远处灯笼、招牌、行人、自行车都应是柔和散景。
- 参考镜头：50mm / 85mm，f/1.4 - f/2.8 写真感。

## 6. 道具锁定

### 6.1 西瓜冰棒

- 红白绿三层，顶部红色果肉，中部白色，底部绿色瓜皮。
- 有黑色小籽点。
- 细木棒手持。
- 适合近景、回眸、举起、贴近脸侧。
- 冰棒是夏日感核心道具之一，但不要每张都强制出现。

### 6.2 Ramune / 水瓶

- 小瓶透明饮料，蓝色瓶盖，清凉夏日感。
- 可贴近脸颊，做眨眼或降温动作。
- 背景可有ラムネ招牌。
- 避免品牌文字过度清晰；可用泛化透明汽水瓶替代。

### 6.3 团扇

- 手持小圆扇，图案为西瓜切片。
- 可与红色竹编篮一起出现。
- 扇面颜色：粉红 / 红色瓜肉、绿色边缘、黑籽。
- 适合全身站姿、店铺门口、灯箱旁边。

### 6.4 红色竹编小篮

- 深红色或朱红色竹编手提篮。
- 竹节手柄，绳结偏紫红，带小木珠。
- 适合挡脸半遮、近景特写、手部动作。
- 篮子里可放小扇子、手帕、风铃、糖果、小饰品。
- 注意：篮子只作为可爱道具，不要变成现代塑料包。

### 6.5 风铃

- 透明玻璃风铃，细蓝色或浅色挂线，下面有白色短纸条。
- 可手举风铃，风铃在阳光下透明发亮。
- 背景可有风铃/夏日小店招牌。
- 动作应轻柔，像听风铃声。

## 7. 构图与镜头分镜

### 镜头 1：回眸冰棒近中景

- 人物背对街道，身体转向画面左侧，脸回头看镜头。
- 左手或右手举西瓜冰棒靠近脸侧。
- 另一只手轻触刘海或耳边碎发。
- 背景是强虚化日本小巷，远处红灯笼形成红色散景。
- 画幅：竖图 2:3。
- 重点：冰棒 + 回眸 + 浴衣袖子 + 腰封侧面。

### 镜头 2：侧身后仰冰棒微笑

- 人物站在街道中央偏右，身体轻微后仰。
- 手持西瓜冰棒，脸偏向镜头，微笑。
- 腰封后结露出一部分，画面有轻微动态感。
- 背景强烈过曝，街道两侧店铺虚化。
- 适合做清爽主视觉。

### 镜头 3：店铺灯箱旁全身站姿

- 人物站在日式店铺门口或灯箱招牌旁。
- 一手遮阳，一手拎红色竹编篮和西瓜团扇。
- 可见完整浴衣、湖蓝腰封、袖子、下摆。
- 背景出现自行车、纸灯笼、日文灯箱。
- 姿态端庄，腿部自然并拢或轻微错开。

### 镜头 4：遮阳俯身俏皮照

- 人物站在店门口，身体向前微微弯腰。
- 一只手举到额前遮阳，眼睛看镜头。
- 另一只手自然垂下，拿篮子或扇子。
- 强日光在手臂和袖子上形成高光。
- 表情温柔带一点俏皮。

### 镜头 5：Ramune 冰水贴脸眨眼

- 人物手持透明饮料瓶贴近脸颊。
- 一只眼睛眨眼，表情可爱但自然。
- 背景有白色遮阳伞、ラムネ招牌、街边店铺。
- 画面更轻松，像夏天逛街时买冷饮后的随手拍。
- 注意瓶子不要挡住太多脸。

### 镜头 6：背影回头拿水瓶

- 从人物背后或侧后方拍摄。
- 湖蓝色腰封大蝴蝶结是核心。
- 人物回头看镜头，手拿透明水瓶。
- 后脑花饰和耳边垂坠装饰清晰。
- 背景为狭窄街道，红色灯笼或红色柱子虚化。
- 重点：背部浴衣纹样 + 腰封结 + 回眸。

### 镜头 7：红篮半遮脸特写

- 人物将红色竹编小篮举到脸前。
- 只露出眼睛和部分脸，视线从篮子后看向镜头。
- 手部和篮子在前景，脸部清晰，背景虚化。
- 篮子纹理、竹节、绳结要细致。
- 整体有俏皮抓拍感。

### 镜头 8：风铃街头竖构图

- 人物站在街边，单手举透明风铃。
- 另一只手轻扶风铃纸条或袖口。
- 背景可以有“BELLE & EMMA”等西式店招，也可有日式冰旗。
- 风铃需要晶莹、轻盈、透明。
- 人物表情微微惊讶或安静凝视。

### 镜头 9：街道远景冰棒全身

- 人物站在小巷中间，手持西瓜冰棒，身体侧转。
- 画面需要明显街道纵深。
- 周围路人很少或虚化，不抢主角。
- 人物头发、浴衣、腰封、冰棒都完整可见。
- 整张图作为 photoset 封面或结尾图。

## 9. 摄影风格

### 9.1 机位

- 中近景：胸像到半身，突出脸、冰棒、袖子。
- 中景：腰部到膝盖，突出腰封和浴衣图案。
- 全身：店铺、灯箱、团扇、小篮全部纳入。
- 背面：展示大蝴蝶结和花饰。
- 前景遮挡：篮子、袖子、冰棒、风铃可靠近镜头形成层次。

### 9.2 镜头感

- 85mm 人像压缩感用于脸部特写。
- 50mm 用于街拍半身和全身。
- 浅景深，背景光斑柔和。
- 轻微过曝，保留皮肤细节。
- 不要锐化过度，不要 HDR 感，不要手机广角畸变。

### 9.3 画质

- 高清写真质感。
- 皮肤细腻但不要塑料磨皮。
- 布料纹理、浴衣织纹、篮子编织、风铃透明质感要清楚。
- 眼睛有自然高光。
- 背景店铺可以虚化但要有真实街道逻辑。

## 13. 画面一致性锁定

为了保证一整套图统一，以下元素应尽量保持一致：

1. **白底果实纹浴衣**：红果、绿叶、淡蓝圆点是识别点。
2. **湖蓝色腰封大蝴蝶结**：每张至少露出腰封色块，背面图必须露出大结。
3. **后侧花簪**：白、黄、蓝、粉花饰固定在右后方或侧后方。
4. **夏日小巷白天场景**：窄街、店铺、灯笼、招牌、遮阳伞。
5. **清透高调日光**：整体明亮，背景可过曝，人物脸部柔和。
6. **道具轮换**：西瓜冰棒、Ramune / 水瓶、风铃、团扇、红篮。
