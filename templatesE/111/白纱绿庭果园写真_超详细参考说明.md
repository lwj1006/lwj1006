# 白纱绿庭果园写真｜超详细参考说明

> 用途：作为下一套图的视觉参考、摄影设定、AI 绘图提示词、角色换装参考或分镜说明。  
> 核心方向：**夏日绿庭、白色薄纱、青梅/绿果、木质平台、柔光森林感、清透自然系写真**。  
> 重要原则：本套图参考的是**场景、服装、光线、构图、姿态与色彩氛围**，不用于识别现实人物身份。

## 1. 总体视觉定位

这套图的核心是“夏日庭院里的清透果园感”。画面几乎完全由三种元素构成：

1. **大量绿色植物**：树叶、灌木、草地、枝条、前景虚化叶片，形成浓密、湿润、自然的庭院包围感。  
2. **白色轻纱服装**：白色蕾丝吊带上衣、轻薄层叠长裙或半透明纱裙，带来干净、柔软、微风感。  
3. **自然采摘道具**：竹编果篮、青梅/绿色小果、木质平台、树枝、叶片，强化“在庭院里摘果子”的日常故事性。

整体不是华丽大片，而是**清爽、自然、安静、带一点夏日甜感的生活写真**。画面重点不在复杂剧情，而在“她与绿色庭院互动”的瞬间：抬手摘叶、低头看果篮、坐在木台边、拿着青梅微笑、手扶枝叶、抱膝坐下等。

## 4. 场景设定

### 4.1 场地类型

场景是一个私密感较强的绿色庭院或小果园，而不是开放城市公园。背景中有大量植物形成包围：

- 左右两侧都有灌木、树枝、藤蔓或大叶植物。
- 中央常有一条隐约可见的草地小径或浅景深绿背景。
- 部分画面出现木质平台、木栈板或低矮木台。
- 地面以草地、泥土、自然庭院地面为主。
- 画面没有明显现代建筑主体，现代元素被植物与虚化隐藏。

### 4.2 空间结构

推荐空间结构：

```text
前景：虚化绿叶 / 枝条 / 低矮植物
中景：人物 + 木质平台 + 果篮 + 青梅
背景：浓密绿植 / 草地小径 / 深绿树影
```

这种三层空间让画面有很强的纵深感。人物始终处于绿色包围中，但白色服装会自然从绿背景中跳出来。

### 4.3 木质平台

木质平台是本套图非常重要的“生活感支点”。它可以是：

- 低矮木台
- 木质露台
- 湿润或略有反光的木板
- 放置果篮与小盘子的采摘平台

木板颜色以浅暖木色为主，纹理自然，最好带一点被阳光晒过的黄色调。它和白裙、绿植形成温柔对比。

## 5. 服装设定

### 5.1 主服装

服装核心为**白色蕾丝吊带上衣 + 白色轻纱长裙/半裙**。

关键特征：

- 白色或奶白色为主。
- 上衣为细肩带设计，边缘有蕾丝、刺绣、褶边或蝴蝶结细绳。
- 胸前有轻微层叠花边，质感柔软，不要硬挺。
- 腰部有镂空或分段设计，但表现为夏日时装感，不要情色化。
- 裙摆为薄纱、雪纺、层叠纱、半透明外层。
- 裙摆可拖在木台或草地上，营造轻盈飘散感。
- 下摆边缘可以有细小蕾丝滚边。

### 5.2 服装质感

材质关键词：

- 蕾丝
- 雪纺
- 薄纱
- 轻透棉纱
- 柔软褶皱
- 半透明外层
- 细腻刺绣
- 微微反光的白色纤维

### 5.3 服装禁忌

为保持这套图的高级感与清爽感，避免：

- 过度暴露或情色化表达。
- 内衣化、睡衣化过强的造型。
- 黑色、红色、金属色等强烈抢镜服装。
- 过分复杂的宫廷礼服或厚重婚纱。
- 过度幼态的童装感。

## 6. 发型与妆容

### 6.1 发型

发型整体是**浅棕色 / 蜂蜜棕 / 暖茶棕的低盘发或松散侧盘发**。

关键点：

- 发色偏浅棕，受阳光照射后有金棕高光。
- 刘海轻薄、空气感，几缕发丝自然垂落。
- 后脑或侧后方为松散低盘发，不要过于整齐。
- 耳侧有碎发、鬓发，增强自然感。
- 发型要有“刚在庭院里活动过”的微乱感。

### 6.2 妆容

妆容是清透甜感，不是浓妆。

- 底妆：白皙通透、轻微柔焦。
- 腮红：淡粉色，位置偏脸颊中央，显得健康温柔。
- 眼妆：自然放大的眼睛，长睫毛，浅棕眼线。
- 唇色：淡粉、蜜桃、珊瑚粉，水润但不夸张。
- 整体气质：温柔、亲近、清新、轻微甜美。

## 7. 道具设计

### 7.1 竹编果篮

竹编果篮是最重要的道具之一。

常见使用方式：

- 双手捧在胸前或腰前。
- 放在木台上，旁边有小盘青梅。
- 单手托住篮子，另一只手拿绿色果子。
- 篮子里放少量青梅、绿果或叶片。

质感要求：

- 天然竹编纹理清晰。
- 颜色为浅黄褐色、暖米色。
- 边缘有白色绑线或竹圈加固。
- 不要变成现代塑料篮。

### 7.2 青梅 / 绿色果实

果实是画面的“夏日采摘主题锚点”。

表现方式：

- 小圆形绿色果子，类似青梅、李子或未成熟小果。
- 可放在白色小盘子中。
- 可散落在木台边缘。
- 可被人物单手举起展示。
- 可放入竹篮中，但不要堆得太满。

颜色：浅青绿、黄绿色、带自然斑点。

### 7.3 枝叶与植物

枝叶用于构图，不只是背景。

- 人物可以抬手触碰上方枝叶。
- 前景可有大面积虚化叶片。
- 树枝可以从画面右上角垂下。
- 人物可以捏住一片小叶子或细枝。

## 8. 光线设计

### 8.1 主光风格

本套图是**明亮自然光 + 柔和漫射 + 局部阳光斑驳**。

光线特点：

- 整体高亮但不过曝。
- 绿色背景被阳光照亮，有清新的夏日感。
- 白色服装保留蕾丝细节，不要一片死白。
- 皮肤有柔和反光，边缘有轻微高光。
- 部分画面有树叶投下的斑驳光影。

### 8.2 色温

推荐色温：

- 主体肤色：暖白、奶油色。
- 背景绿植：明亮黄绿、青绿、深绿混合。
- 高光：轻微暖调。
- 阴影：保持柔和，不要压成黑色。

### 8.3 避免的光线

- 夜景硬闪光。
- 强烈棚拍感。
- 赛博霓虹色。
- 过度 HDR。
- 过度磨皮导致没有真实光影。
- 绿色溢色严重覆盖皮肤。

## 9. 色彩方案

### 9.1 主色

| 色彩 | 作用 |
|---|---|
| 白色 / 奶白 | 服装主体，清透、柔软、干净 |
| 青绿色 / 黄绿色 | 植物、青梅、背景氛围 |
| 浅木色 | 木台、果篮，提供自然暖调 |
| 淡粉肤色 | 腮红、唇色，增强甜感 |

### 9.2 色彩比例

```text
绿色植物：55%
白色服装：25%
暖木色与竹篮：10%
肤色与粉色妆容：8%
其他小道具：2%
```

### 9.3 颜色氛围

整体应该是“绿得很满，但不脏；白得很亮，但不刺眼”。画面需要保持空气感和夏日水汽感。

## 10. 构图与镜头语言

### 10.1 镜头类型

建议使用：

- 50mm 人像镜头感
- 85mm 浅景深特写
- 35mm 环境人像
- 大光圈背景虚化
- 柔焦边缘

### 10.2 常用构图

1. **中心人物 + 两侧绿植包围**  
   人物在中间，左右绿叶形成自然框架。

2. **前景虚化叶片 + 中景人物**  
   大片绿叶在前景遮挡一部分画面，增强偷窥感与自然感。

3. **木台横向线条 + 坐姿人物**  
   木台形成稳定横线，人物白裙垂落打破直线。

4. **右上树枝 + 抬手动作**  
   人物向上触碰枝叶，手臂形成优雅斜线。

5. **近景半身 + 叶片或果实道具**  
   人物表情与手部道具成为焦点，背景完全虚化。

## 11. 姿态设计

### 11.1 站姿

适合动作：

- 抬头看树枝，右手向上触碰叶子。
- 一手轻轻提起裙摆，另一手伸向树梢。
- 身体微微侧转，肩颈线条放松。
- 表情是好奇、温柔、微张嘴或轻笑。

### 11.2 坐姿

适合动作：

- 坐在木台边缘，双腿自然并拢或交叠。
- 双手捧着竹篮，正面看镜头。
- 侧坐在木台上，一手拿青梅，一手扶着篮子。
- 抱膝坐下，下巴轻靠手背。
- 赤脚或脚部自然落在草地/木台边缘，保持生活感。

### 11.3 手部动作

手部动作要细腻自然：

- 捏住一片小叶子。
- 托着绿色果实。
- 轻扶脸颊。
- 托住竹篮边缘。
- 拨开前景叶片。
- 轻轻提起白纱裙摆。

避免手指僵硬、过长、错位或出现多余手指。

## 12. 表情设定

表情以自然、温柔、轻甜为主。

可选表情：

- 抬头看叶子的好奇表情。
- 看镜头的温柔微笑。
- 低头看果篮的安静表情。
- 轻咬或轻触果子的生活感表情。
- 下巴托手的亲近感表情。
- 眼睛微弯的清爽笑容。

不要使用夸张卖萌、强烈媚态、挑逗表情或过度商业写真表情。

## 18. 推荐画幅与镜头参数

### 18.1 画幅

- 竖图：2:3 或 3:4，适合全身和半身。
- 方图：1:1，适合近景头像和采摘表情。
- 横图：不优先，除非强调庭院空间。

### 18.2 镜头感

| 画面类型 | 推荐镜头感 |
|---|---|
| 全身站姿 | 35mm / 50mm |
| 坐姿木台 | 50mm |
| 半身捧篮 | 50mm / 85mm |
| 近景微笑 | 85mm |
| 前景叶片虚化 | 大光圈 85mm |

### 18.3 景深

- 背景虚化要明显，但不能完全看不出庭院结构。
- 前景叶片可以非常虚化，作为绿色柔雾。
- 人物眼睛、脸部、手中果实或竹篮边缘保持清晰。

## 19. 生成时的重点控制

1. **白色服装必须保留蕾丝与纱的层次**，不要变成纯白块。  
2. **绿色背景要丰富但干净**，避免杂乱脏绿。  
3. **人物姿态要自然**，像真实采摘或庭院休息，不要摆拍过硬。  
4. **手部一定要重点修正**，因为摘叶、捧篮、拿果都很容易出错。  
5. **竹篮与青梅要小而真实**，不要变成巨大水果或花篮。  
6. **整体年龄感为成年女性**，避免幼态比例和儿童化气质。  
7. **光线要高亮清透**，但脸部和白裙不要过曝。  
8. **画面情绪是温柔、清新、生活化**，不是性感挑逗。

## 20. 推荐出图组合

如果要做一整套 6～9 张图，可以按以下顺序：

1. 站在绿植中抬手摘叶，作为开场图。  
2. 坐在木台上双手捧竹篮，建立采摘主题。  
3. 侧坐木台品尝青梅，增加生活动作。  
4. 抱膝坐姿托腮，做柔和情绪图。  
5. 近景微笑拿叶片，突出脸部与妆容。  
6. 树下站姿托篮，展示庭院环境。  
7. 举起青梅微笑，作为甜美互动图。  
8. 低头看竹篮，做安静收尾。  
9. 半身前景叶片虚化，作为精修封面。
