## 0. 总体概念

这一套图的主题可以概括为：


## 2.1 主色

```text
icy blue, silver white, crystal clear, soft lavender pink, black, pearl gray
```

中文：

```text
冰蓝、银白、透明水晶、浅薰衣草粉、黑色、珍珠灰
```

## 2.2 色彩比例

大致比例：

```text
冰蓝礼服：35%
银白水晶与翅膀：30%
黑色背景：20%
肤色与粉色妆容：10%
局部暖白灯光：5%
```

## 2.3 关键色彩关系

```text
icy blue dress × silver crystal × black background × pink bloom light
```

中文：

```text
冰蓝礼服 × 银白水晶 × 黑色背景 × 粉色梦幻泛光
```

黑色背景不是沉重的黑，而是为了托出银白和冰蓝的闪耀。  
这套图不能把背景做成纯白，因为纯白会失去“水晶夜场”的戏剧感。

## 2.4 色彩禁忌

避免：

```text

```

中文：

```text
不要薄荷绿花房，不要田园白花，不要暖红裙，不要热带植物，不要复古棕色房间，不要海边阳光，不要赛博霓虹，不要厚重哥特黑裙
```

这套虽然用黑背景，但本质不是哥特，而是：

```text
silver crystal fairy princess
```

# 3. 场景系统

## 3.1 黑色背景

```text
black studio backdrop, dark paneled wall, theatrical shadow background
```

中文：

```text
黑色棚拍背景，深色护墙板，舞台式暗背景
```

作用：

- 提升银白水晶亮度。
- 让冰蓝礼服更冷、更亮。
- 让星芒和水雾颗粒显得明显。
- 产生夜晚舞台感。
- 避免画面过甜，保留高级感。

## 3.2 水晶珠帘

右侧和上方大量垂落珠帘：

```text
hanging crystal bead curtains, pearl strands, translucent discs, chandelier drops
```

中文：

```text
垂挂水晶珠帘，珍珠串，透明圆片，吊灯水晶坠
```

这是本套最强的背景识别元素。  
珠帘必须密集、有纵向节奏，不能只是几根稀疏线条。

## 3.3 吊灯与强光灯

画面左上或上方经常出现强光源：

```text
bright chandelier bulb, glowing lamp, starburst highlights
```

中文：

```text
明亮吊灯灯泡，发光灯源，星芒高光
```

这个光源要明显过曝，并产生：

- 星芒。
- 彩虹边缘。
- 镜头眩光。
- 高光溢出。
- 雾化泛光。

## 3.4 银白桌面与派对道具

左侧有小桌、蛋糕、杯子、银白玫瑰、珠链、烛台等：

```text
silver table setup, white roses, glass goblet, birthday cake, candle holder, pearl decorations
```

中文：

```text
银白桌面布置，白玫瑰，玻璃高脚杯，生日蛋糕，烛台，珍珠装饰
```

这些道具强化“生日派对 / 水晶舞台 / 公主庆典”氛围。

# 4. 人物造型系统

## 4.1 发型

核心发型：

```text
messy high updo, fluffy copper-brown hair, curly loose tendrils, crystal hair clip
```

中文：

```text
蓬松微乱高盘发，铜棕色卷发，脸侧卷曲碎发，水晶发夹
```

这套发型比薄荷绿那套更华丽：

- 头顶蓬松高度更高。
- 后脑发团更大。
- 额前有卷曲碎刘海。
- 两侧垂落卷发。
- 发饰偏银白水晶。
- 逆光让发丝边缘发亮。

## 4.2 妆容

```text
soft pink blush, glossy rose lips, glitter eye makeup, dewy skin, tiny crystal face stickers
```

中文：

```text
柔粉腮红，水润玫瑰唇，闪粉眼妆，水光肌，小水晶脸贴
```

妆容必须与舞台感配合：

- 眼下可以有小亮片。
- 鼻梁和眼角可以有微闪。
- 腮红偏粉。
- 唇色水润但不浓重。
- 皮肤受粉白灯光影响，有柔雾感。

## 4.3 饰品

重要饰品：

```text
large silver crystal necklace, dangling pearl earrings, silver bracelet, crystal hair ornament
```

中文：

```text
大型银白水晶项链，垂坠珍珠耳饰，银色手镯，水晶发饰
```

项链很关键，因为它把上半身从“普通礼服”提升到“水晶公主”级别。

# 5. 服装系统

## 5.1 主服装

```text
icy blue strapless princess dress, structured corset bodice, beaded grid pattern, sparkling rhinestones, layered tulle skirt
```

中文：

```text
冰蓝色无肩带公主裙，结构感束身上衣，珠绣格纹，闪亮水钻，层叠薄纱裙摆
```

## 5.2 上身结构

礼服上身非常重要：

```text
straight neckline, fitted bodice, vertical seams, grid beadwork, small rhinestones at intersections
```

中文：

```text
平直领口，贴身束身衣结构，纵向缝线，格纹珠绣，交点处点缀小水钻
```

特点：

- 上半身像冰晶盔甲。
- 但材质仍然柔和，不是金属。
- 格纹和珠点让礼服非常精致。
- 冰蓝底色上叠加银白珠线。

## 5.3 裙摆结构

```text
voluminous short princess skirt, diamond grid beadwork, layered translucent tulle, curly ruffled hem
```

中文：

```text
蓬松短款公主裙，菱格珠绣，层叠透明薄纱，卷曲荷叶边下摆
```

裙摆是这套的最大视觉体积：

- 横向展开明显。
- 下摆有白色透明薄纱卷边。
- 菱格结构像水晶笼。
- 珠点在光下闪烁。
- 适合正面坐姿和半身站姿。

## 5.4 翅膀

```text
large transparent fairy wings, silver glitter veins, translucent mesh, glowing edges
```

中文：

```text
大型透明精灵翅膀，银色闪粉脉络，透明网纱，发光边缘
```

翅膀必须是本套核心，而不是小装饰。  
它要占据人物背后左右两侧，像舞台装置一样展开。

# 6. 光线系统

## 6.1 主光逻辑

```text
strong backlight, overexposed chandelier light, soft frontal fill, glitter starburst, pink-white bloom
```

中文：


这套光线非常关键。

高光表现为：

```text
sparkles, lens flares, rainbow refraction, crystal highlights, glowing wing edges
```

中文：

```text
闪点，镜头眩光，彩虹折射，水晶高光，翅膀边缘发光
```

## 6.3 雾化与柔焦

画面整体有明显：

```text
dream filter, soft haze, bloom, misty particles
```

中文：

```text
梦幻滤镜，柔雾，泛光，雾状颗粒
```

这套不是锐利商业棚拍，而是：

```text
crystal fantasy haze
```

中文：

```text
水晶幻想雾感
```

## 6.4 光线禁忌

避免：

```text
flat light, natural daylight only, hard shadow without bloom, no sparkle, no backlight
```

中文：

```text
不要平光，不要纯自然日光，不要没有泛光的硬阴影，不要没有闪点，不要没有逆光
```

# 7. 构图系统

## 7.1 中心公主构图

人物常在中央：

```text
centered princess composition, symmetrical wings, skirt spreading horizontally
```

中文：

```text
中心公主式构图，对称翅膀，裙摆横向展开
```

这类构图最适合表现礼服体积和翅膀。

## 7.2 珠帘纵向构图

```text
vertical crystal bead curtains framing the subject
```

中文：

```text
垂直水晶珠帘框住人物
```

珠帘形成大量竖线，与裙摆的横向展开形成对比。

## 7.3 左光右帘构图

常见关系：

```text
bright chandelier or lamp on the left, dense crystal curtain on the right, subject in the middle
```

中文：

```text
左侧强灯或吊灯，右侧密集水晶珠帘，人物居中
```

## 7.4 半身近景构图

适合突出：

- 水晶项链。
- 发饰。
- 妆容。
- 透明翅膀纹理。
- 礼服胸衣珠绣。

## 7.5 仰望手掌构图

人物伸手接光或接“星尘”：

```text
hand raised toward sparkling light, looking upward
```

中文：

```text
手掌抬向闪耀灯光，仰头看光
```

这是本套最有叙事的动作之一。
