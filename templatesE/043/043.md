# Set 19 — 天台泳池 / 蓝色水感 / 高楼背景 超详细图像拆解 MD

> 用途：把这套 9 张图整理成可复用的视觉设定、构图语言、服装系统、动作库、光线逻辑与提示词模板。  
> 说明：这是 **图像分析 + 提示词整理文档**，不是画图任务。  
> 风格方向：都市高楼背景、天台泳池、水蓝色服装、水面反射、轻透罩衫、夏日清凉写真。

---

## 0. 总体概念

这一套的核心是：

```text
都市高层天台泳池 / 冷蓝水面 / 蓝色泳装 / 透明蓝罩衫 / 湿润水光 / 高楼虚化背景 / 游艇或泳池平台结构 / 清亮夏日人像
```

整套图和前几套卧室、植物、侘寂风格完全不同。  
这里的重点不是室内氛围，而是 **城市度假感 + 天台泳池写真 + 蓝色水系视觉**。

画面里的主要元素：

- 高楼背景：提供都市感与高度感
- 泳池水面：提供反射、波纹、冷蓝色基底
- 蓝色服装：与水面统一
- 透明罩衫：增加轻薄层次和动态
- 木质或船舱式背景：提供温暖对比
- 白色池边平台：形成干净几何线条
- 人物姿态：坐、站、涉水、泼水、回眸、扎发、眨眼

这一套的关键词可以概括为：

```text
blue pool, rooftop city, summer water, translucent cover-up, urban resort, playful glamour, clean bright portrait
```

中文：

```text
蓝色泳池，城市天台，夏日水感，半透明罩衫，都市度假，俏皮明亮写真
```

## 2. 色彩系统

### 2.1 主色

```text
aqua blue, sky blue, pool blue, deep blue, white, pale skin tone, warm wood brown, soft grey city tones
```

中文：

```text
水蓝，天空蓝，泳池蓝，深蓝，白色，浅肤色，暖木棕，柔灰城市色
```

### 2.2 色彩比例

大致比例：

```text
泳池水蓝：35%
服装蓝：25%
白色平台/高光：15%
城市灰蓝背景：15%
木质棕色背景：7%
银色饰品/小高光：3%
```

### 2.3 色彩逻辑

这一套的颜色非常集中，核心公式是：

```text
蓝色泳装 + 蓝色水面 + 灰蓝城市背景 + 白色平台
```

为了避免画面过冷，局部加入：

- 暖木色墙面
- 肤色暖调
- 轻微粉色妆容
- 红色指甲作为很小的色点

整体没有复杂配色，重点是让蓝色形成完整主题。

## 3. 场景系统

### 3.1 天台泳池

场景像是高楼顶部或高层露台的泳池区：

```text
rooftop pool, infinity pool edge, shallow water, white pool ledge, glass railing, city buildings behind
```

中文：

```text
天台泳池，无边泳池边缘，浅水区，白色池边平台，玻璃围栏，城市高楼背景
```

泳池本身承担两件事：

1. 作为蓝色主背景  
2. 作为水面反射与动作互动道具  

### 3.2 城市高楼背景

背景中的高楼被虚化，形成灰蓝色矩形网格：

```text
blurred high-rise buildings, soft city bokeh, urban glass towers
```

中文：

```text
虚化高楼，柔和城市虚景，玻璃幕墙建筑
```

这让画面有“高空泳池”的高级感。

### 3.3 木质平台 / 船舱式墙面

部分图的背景出现木质墙面、圆角窗或横向结构，很像游艇或泳池旁休息区：

```text
warm wooden wall, rounded rectangular windows, yacht-like deck background
```

中文：

```text
暖木色墙面，圆角矩形窗，游艇甲板感背景
```

这个元素的作用是给大面积蓝色降温，提供暖色反差。

## 7. 光线系统



### 7.2 光线特征

```text

```

## 8. 构图系统

### 8.1 常见构图

这一套的构图主要分成四类：

1. **涉水半身构图**  
   人物站在水中，水面到大腿或腰部，城市背景虚化。

2. **池边坐姿构图**  
   人物坐在白色池边平台，腿部形成斜线或交叉线。

3. **俯拍近景构图**  
   镜头从上方看向人物，人物做手势或亲近镜头。

4. **扎发近景构图**  
   双手举起整理头发，手臂形成拱形框架。

### 8.2 背景构图

背景主要有两套：

- 灰蓝高楼背景：冷感、都市、纵深
- 木质墙面背景：暖感、游艇、度假

### 8.3 线条系统

- 泳池边缘：强几何线
- 水面波纹：流动线
- 高楼窗格：竖向网格线
- 罩衫绑带：细线
- 长发：曲线
- 手臂：框架线
