## 0. 总体概念

这一套图的主题可以概括为：

```text
薄荷绿春日花房里的透明蝴蝶仙女写真
```

它和前一套红裙金鱼房间完全不同。前一套是：

```text
deep red / tropical / vintage / warm wood / goldfish / strong red-green contrast
```

而这一套是：

```text
mint green / white blossoms / translucent butterfly / pale floral organza / high-key dream haze / soft fairy atmosphere
```

中文概括：

```text
薄荷绿、白花、透明蝴蝶、浅色木桌、轻纱花裙、柔雾光、仙气棚景
```

这套图的核心不是强烈戏剧冲突，而是 **淡、透、柔、亮、轻、漂浮感**。

它最重要的视觉体验是：

```text
空气中像有一层绿色薄雾，白色花枝从左侧伸进来，透明蝴蝶吊饰从右侧垂下，人物穿着半透明花纹纱裙坐在浅木桌上，像春天花房里短暂停留的精灵。
```

# 3. 场景系统

## 3.1 薄荷绿背景

背景是非常干净的单色薄荷绿：

```text
solid mint green studio backdrop
```

中文：

```text
单色薄荷绿棚拍背景
```

它没有复杂房间结构，没有窗框，没有墙画，没有柜子。  
背景本身就是气氛容器。

作用：

- 提供纯净梦幻色调。
- 让白花、透明蝴蝶、纱裙全部变得轻。
- 避免真实空间干扰。
- 增强仙气和设计感。

## 3.2 白花枝

左侧反复出现大量白色花枝：

```text
white blossom branches, green leaves, potted flowering tree
```

中文：

```text
白色花枝，绿色叶片，盆栽开花小树
```

视觉作用：

- 形成左侧前景框架。
- 制造春日感。
- 提供高光点。
- 与人物的白纱裙呼应。
- 让画面具有自然生长的方向。

## 3.3 浅木桌

人物多数坐在浅木色桌面或靠在桌边：

```text
light wooden console table with drawers
```

中文：

```text
带抽屉的浅木色控制台桌
```

桌子作用：

- 让人物有坐姿支点。
- 提供温暖中性色。
- 稳定画面下半部。
- 避免整体过于漂浮没有落点。

## 3.4 透明蝴蝶吊饰

右侧和人物附近有多条透明蝴蝶与珍珠串吊饰：

```text
translucent green butterfly ornaments, hanging pearl bead strings
```

中文：

```text
半透明绿色蝴蝶吊饰，垂挂珍珠珠串
```

这是本套最具识别性的道具之一。

作用：

- 强化“仙气 / 精灵 / 春日幻想”。
- 增加纵向线条。
- 在右侧补充画面层次。
- 与服装透明材质统一。
- 产生微小闪光和折射。

# 4. 人物造型系统

## 4.1 发型

发型核心：

```text
messy high bun, loose tendrils, dark brown soft hair, airy wisps around face
```

中文：

```text
微乱高盘发，脸侧垂落碎发，深棕柔软发丝，空气感碎发
```

这一套发型不是长发披肩，而是：

```text
loose updo with romantic flyaway strands
```

中文：

```text
松散盘发 + 浪漫飞散碎发
```

特点：

- 头发收在后上方，露出颈部。
- 两侧碎发自然垂落。
- 发丝不整齐，有风吹感。
- 头顶蓬松，不贴头皮。
- 逆光和高调柔光让发丝边缘发亮。

## 4.2 脸部妆容

```text
dewy skin, peach-pink blush, glossy peach lips, soft orange-pink eye makeup
```

中文：

```text
水光肌，桃粉腮红，水润蜜桃唇，柔和橘粉眼妆
```

这套妆感比红裙那套更轻：

- 腮红更淡。
- 唇色偏蜜桃橘粉。
- 眼妆清透。
- 皮肤高光很柔。
- 整体像被薄荷绿光包裹。

## 4.3 眼神

常见眼神：

```text
looking upward at blossoms
looking sideways at flowers
soft direct gaze
eyes lowered toward hand
quiet dreamy profile
```

中文：

```text
仰望白花，侧眼看花，柔和直视，低头看手，安静梦幻侧脸
```

眼神不能太锐利。  
应保持：

```text
soft, curious, gentle, slightly distant
```

中文：

```text
柔、好奇、温和、略微出神
```

# 7. 光线系统

## 7.1 主光特点

```text
soft high-key diffused light, mint-tinted glow, gentle backlight, dreamy overexposure
```

中文：

```text
高调柔和散射光，薄荷绿染色光，温柔逆光，梦幻轻微过曝
```

这套不是强烈硬光，而是：

```text
overexposed pastel haze
```

中文：

```text
粉彩轻过曝雾感
```

## 7.2 光线方向

常见光线逻辑：

- 左侧白花区域光最亮。
- 人物脸部有柔和正面补光。
- 纱裙边缘被光照透。
- 背景薄荷绿有均匀柔光。
- 珍珠串和蝴蝶产生小高光。
- 白花会出现明显发光边缘。

## 7.3 雾化效果

这一套必须保留：

```text
soft bloom, dreamy haze, low contrast, pastel diffusion
```

中文：

```text
柔和泛光，梦幻薄雾，低对比，粉彩扩散
```

画面不能太锐、太硬、太商业棚拍。  
适合略微朦胧，像镜头前有薄纱滤镜。

## 7.4 光效关键词

```text
soft bloom, ethereal glow, diffused daylight, translucent fabric glow, butterfly sparkle, pearl highlights, spring morning haze
```

中文：

```text
柔和泛光，空灵光晕，散射日光，透明纱料发光，蝴蝶闪光，珍珠高光，春日清晨薄雾
```

# 8. 构图系统

## 8.1 左花右蝶构图

最重要的构图关系：

```text
white blossom branches on the left, hanging butterfly ornaments on the right, subject centered or slightly right
```

中文：

```text
左侧白花枝，右侧垂挂蝴蝶吊饰，人物居中或略偏右
```

这让画面左右平衡：

- 左边自然植物体积大。
- 右边珠串和蝴蝶轻而细。
- 人物处于中间，被花与蝶包围。

## 8.2 桌面坐姿构图

多数图里人物坐在浅木桌上：

```text
seated on a pale wooden console table, one knee raised, dress flowing over table edge
```

中文：

```text
坐在浅木桌上，一膝抬起，纱裙从桌沿垂落
```

这种构图能表现：

- 腿部曲线。
- 纱裙透明层次。
- 桌面横线。
- 轻盈漂浮感与稳定支撑感的对比。

## 8.3 近景花枝构图

```text
close-up with white blossoms near face, shallow depth of field
```

中文：

```text
白花靠近脸部的近景，浅景深
```

适合表现：

- 眼神。
- 肌肤水光。
- 花与脸的柔和关系。
- 透明纱衣的细节。

## 8.4 侧脸仰望构图

```text
profile looking upward toward white blossoms
```

中文：

```text
侧脸仰望白花
```

这是这套非常重要的动作。  
它能产生“精灵在看春花”的叙事感。

## 8.5 背身回望构图

```text
over-the-shoulder gaze, translucent floral back of dress, butterfly near lips
```

中文：

```text
背身回望，透明花纹背部纱裙，蝴蝶靠近嘴边
```

背部半透明纱衣和蝴蝶道具是这套的高级图像点。
