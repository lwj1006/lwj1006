# Set 16 — 白棚衬衫吊带 / 高调极简凳子坐姿 超详细图像拆解 MD

> 用途：把这套 8 张图拆解成可复用的视觉设定、构图语言、服装系统、动作库、光线逻辑与提示词模板。  
> 注意：这是 **图像分析 + 提示词整理文档**，不是画图任务。

## 0. 总体概念

这一套的核心非常明确：

```text
纯白棚拍 / 白色衬衫 / 白色蕾丝吊带 / 白袜 / 白色高脚凳 / 栗棕长卷发 / 高调柔光 / 清透甜美人像
```

和上一套 MOTTI 暗红木墙白蕾丝不同，这套完全抛弃深色背景，转向 **极简、高调、干净、空气感、白色系少女写真**。  
画面几乎只保留三个元素：

1. 人物  
2. 白色服装  
3. 白色背景 + 白色凳子  

整体像一组棚拍模卡，也像“白衬衫主题写真”。重点不是场景叙事，而是：

- 脸部清透感
- 长卷发体积
- 白衬衫松垮感
- 肩颈与锁骨线条
- 坐姿腿部几何
- 高调白背景里的柔软阴影

### 1.1 核心关键词

英文关键词：

```text
high-key white studio portrait, oversized white shirt, white lace camisole, white socks, white stool, soft clean lighting, long chestnut wavy hair, delicate beauty makeup, airy minimal composition, pure white background, soft feminine sitting pose
```

中文关键词：

```text
高调白棚人像，宽松白衬衫，白色蕾丝吊带，白袜，白色高脚凳，干净柔光，栗棕长卷发，精致清透妆，空气感极简构图，纯白背景，柔软女性坐姿
```

### 1.2 风格定位

这一套不是复古，不是暗房，不是电影感低调光。  
它更接近：

```text
干净棚拍写真 / 高调白色系 / 少女感模卡 / 极简时装试拍 / 柔光甜美人像
```

风格关键在于“白”：

- 背景白
- 衬衫白
- 吊带白
- 袜子白
- 凳子白
- 皮肤也被柔光打得偏白皙

因此必须依靠 **头发的深栗棕色、眼妆、嘴唇、腿部线条、阴影层次** 来避免画面糊成一片。

## 2. 色彩系统

### 2.1 主色

```text
pure white, ivory white, soft gray shadow, pale skin tone, chestnut brown hair, light pink makeup
```

中文：

```text
纯白、象牙白、浅灰阴影、白皙肤色、栗棕发色、淡粉妆容
```

### 2.2 色彩比例

大致比例：

```text
白色背景/白衣/白凳：70%
肤色：15%
栗棕头发：12%
粉色妆容细节：3%
```

### 2.3 色彩逻辑

这套图没有复杂调色，重点是：

- 白色不要死白，要保留浅灰褶皱。
- 皮肤不能和背景完全融掉，需要有柔和轮廓。
- 头发是唯一主要深色块，用来平衡画面。
- 嘴唇和眼妆提供轻微粉色焦点。
- 光影要非常柔，不能有硬闪质感。

## 3. 场景与道具系统

### 3.1 场景

场景是极简白棚：

```text
white seamless studio, pure white background, soft floor, faint window-like light pattern
```

中文：

```text
纯白无缝棚，白色背景，浅白地面，背景有极淡的窗影或柔光斑
```

画面里几乎没有家具，只有一把白色高脚凳。  
这让场景变成“身体姿态展示台”。

### 3.2 道具

唯一核心道具：

```text
white stool / white high stool
```

道具功能：

- 支撑坐姿
- 拉长腿部线条
- 形成几何结构
- 让人物不完全瘫坐在地面
- 让衬衫下摆和腿部产生层次

### 3.3 背景光斑

多张图背景有浅淡的窗格或光影：

```text
very soft window shadow, pale rectangular light patch, barely visible geometric shadow
```

这个细节非常重要。  
它让白背景不死板，但仍然不破坏极简感。

## 4. 服装系统

### 4.1 核心服装

```text
oversized white button-up shirt, white lace camisole, white socks
```

中文：

```text
宽松白色纽扣衬衫，白色蕾丝吊带，白色中筒袜
```

### 4.2 服装状态

这套图的重点不是“穿得整齐”，而是“松垮自然”：

- 白衬衫宽松
- 衬衫肩部滑落
- 一侧露出吊带肩带
- 领口打开
- 袖口宽大
- 下摆包住身体
- 吊带蕾丝边若隐若现
- 白袜增加居家/棚拍清纯感

### 4.3 服装视觉价值

白衬衫的作用：

- 制造白色大块面
- 增加褶皱层次
- 让身体线条不过度直白
- 形成“刚起床/白衬衫写真”的轻松感

白蕾丝吊带的作用：

- 提供细节纹理
- 强化肩颈与锁骨
- 让画面从普通衬衫变成写真风格
- 在近景中提供精致感

白袜的作用：

- 统一白色系统
- 让腿部线条更柔软
- 增加少女感
- 在全身坐姿中平衡脚部区域

## 6. 光线系统

### 6.1 主光

```text
large softbox frontal light, high-key studio lighting, diffused white light
```

中文：

```text
大面积柔光箱正面光，高调棚拍光，漫射白光
```

### 6.2 补光

白色背景与白地面会自然反射光线：

```text
white bounce fill, low contrast shadows, soft shadow under chin and legs
```

### 6.3 光线特点

- 阴影非常浅
- 皮肤无明显硬影
- 背景接近纯白
- 衣服褶皱保留少量灰度
- 腿部和锁骨有柔和立体感
- 整体不偏黄，不偏蓝，接近中性白光

### 6.4 避免事项

这套不能用：

- 暗调电影光
- 强烈逆光
- 彩色光
- 霓虹
- 厚重阴影
- 复杂室内背景

否则会破坏“白棚极简”的统一性。
