# 蓝蝶花境梦幻写真｜超详细参考说明

> 用途：将当前这组参考图整理成可复用的视觉设定、拍摄语言、构图结构和生成提示词。  
> 核心目标：复刻“暗木室内 + 冷蓝花海 + 蝴蝶精灵感 + 透明纱幕 + 高光梦幻摄影”的整体氛围，而不是复刻真实人物身份。  
> 角色设定建议：成年女性模特，柔和精致五官，梦幻花仙 / 蓝蝶少女感，但表达时保持成人设定、非低龄化。

---

## 1. 整体风格定位

这组图是典型的 **室内梦幻花境写真**，主视觉由蓝色蝴蝶、蓝白花束、深色木质背景、半透明纱帘、珠链、玻璃器皿和柔光高光共同构成。画面不是现实主义花房，而是偏“摄影棚搭建的幻想场景”：背景偏暗，主体和花束被强烈的柔光打亮，形成类似童话标本室、蓝蝶温室、梦境花园的氛围。

关键词：

- 蓝蝶花境
- 梦幻室内花房
- 透明纱幕
- 玻璃花瓶与珠链
- 蓝白紫花束
- 暗木背景
- 高光柔焦
- 轻雾感 / 透光感
- 花仙子气质
- 甜美但安静的凝视
- 近距离人像写真
- 纵向 2:3 海报构图

整体观感介于 **少女漫画封面、梦幻婚纱样片、花艺棚拍、蝴蝶标本童话场景** 之间。画面明亮处偏冷白，阴影处偏深棕、灰蓝，局部用蓝色蝴蝶和蓝花作为视觉锚点。

## 2. 色彩系统

### 2.1 主色

1. **冷蓝 / 宝石蓝 / 天蓝**  
   用于蝴蝶、花瓣、面部贴纸、局部花饰。蓝色要有清透感，不要过于电光或赛博。

2. **白色 / 乳白 / 透明白**  
   用于纱幕、纱裙、白花、玻璃器皿、珠链和高光。白色是画面的空气感来源。

3. **深棕 / 黑棕 / 暗木色**  
   用于背景的木质柜体、钢琴或旧家具。它提供复古深度，不能被纯白背景替代。

4. **淡紫 / 粉紫**  
   部分图从蓝色花境切换到粉紫蝴蝶与紫藤花，形成同一套里的变体。粉紫要柔，不要变成高饱和玫红。

### 2.2 辅助色

- 玻璃透明灰
- 珍珠白
- 叶片绿
- 肤色暖粉
- 局部银白反光

### 2.3 调色方向

- 亮部：冷白、微蓝、柔和过曝。
- 暗部：深棕、灰蓝、带一点雾化，不要死黑。
- 肤色：白皙柔粉，保留健康暖度，不要惨白。
- 蓝色：集中在花、蝴蝶、贴纸、服装暗纹上，作为主题识别点。
- 紫色变体：适合后半套，维持同样灯光和布景，只把蓝蝶与蓝花替换为粉紫蝴蝶、紫藤和粉紫花束。

## 3. 场景与道具设定

### 3.1 背景空间

场景是一个室内棚拍花境，背景以深色复古家具为主。可理解为：

- 深棕色木柜、旧钢琴、木质墙面或复古柜门。
- 后景悬挂半透明白纱或淡蓝纱幕。
- 纱幕上可点缀小蝴蝶贴片或蝴蝶装饰。
- 背景存在纵向花束：蓝紫色藤花、垂挂花串、白花枝。
- 右侧或后方可出现白色鸟笼、珍珠链、玻璃瓶、相框、旧家具细节。

重要：背景不是空白棚拍，不是纯现代极简空间。必须保留“暗木 + 花艺 + 纱幕 + 玻璃 + 珠链”的复合层次。

### 3.2 花材

主要花材：

- 蓝色蝴蝶兰 / 蓝色绢花 / 蓝色大瓣花
- 浅蓝绣球或紫藤状垂花
- 白玫瑰 / 白色小花
- 淡紫花束
- 绿色细叶和轻柔枝条

花艺形态：

- 大量花束围绕人物两侧，形成半包围式前景。
- 前景花朵有明显虚化，制造景深。
- 蓝花和白花混合，局部垂落，形成“花幕”。
- 不追求真实园艺逻辑，更像经过设计的摄影棚装置。

### 3.3 蝴蝶元素

蝴蝶是本套最关键的符号。

出现方式：

- 头发两侧夹有蓝色或粉紫蝴蝶发饰。
- 手指间轻捧一只蓝色蝴蝶。
- 肩膀、发丝、花束、玻璃器皿上有蝴蝶装饰。
- 背景纱幕上可有小型蓝蝶点缀。
- 面颊上有细小蓝色蝴蝶贴纸和亮片。

蝴蝶颜色：

- 蓝色版本：明亮湖蓝、宝石蓝、黑边翅纹。
- 紫色版本：粉紫、淡紫、带微透明质感。

注意：蝴蝶应为“装饰性、梦幻、轻盈”，不要变成昆虫特写，不要恐怖，不要大量真实昆虫爬满身体。

### 3.4 玻璃与珠链

常见道具：

- 透明玻璃花瓶
- 透明糖罐 / 香水瓶 / 玻璃罐
- 珍珠链散落在地面或花瓶旁
- 玻璃器皿上贴蝴蝶
- 白色鸟笼作为后景装饰

这些道具提供“晶莹、易碎、梦幻”的质感，是画面高级感的重要部分。

## 4. 人物造型设定

### 4.1 人物气质

人物是成年女性，整体气质为：

- 柔软、梦幻、安静
- 略带无辜感，但不是幼态化
- 凝视镜头时带一点空灵和脆弱感
- 不笑或微微张唇，表情偏静态
- 部分画面可以轻轻低头、侧脸、回望、手触蝴蝶

避免：夸张大笑、强烈性感挑逗、过度商业网红姿势、运动感、街拍感。

### 4.2 发型

核心发型：

- 深棕黑色长卷发。
- 发量蓬松，微乱，有空气感。
- 中分或轻微偏分，额前有自然碎发。
- 卷度偏大波浪，发丝在光下有柔亮反光。
- 蝴蝶发饰夹在两侧发间。

发型细节：

- 不要过于整齐，必须有风吹感和松散感。
- 发丝可遮挡一部分额头或脸颊，增加柔弱和动态。
- 近景图里头发应有明显高光和卷曲纹理。

### 4.3 妆容

妆容重点：

- 眼妆大而柔，睫毛明显但不厚重。
- 眼周偏粉，卧蚕明显。
- 唇部水光感强，颜色为粉玫瑰、蜜桃粉或透明红。
- 腮红集中在眼下和鼻尖，营造梦幻易碎感。
- 面颊有蓝色 / 紫色小蝴蝶贴纸和亮片点缀。

妆容关键词：水光唇、粉色眼下腮红、玻璃感皮肤、蓝蝶贴纸、泪光闪粉。

### 4.4 服装

主服装：

- 浅蓝、白色、淡紫色的轻纱连衣裙。
- 面料应为透明纱、羽毛纱、蕾丝、刺绣纱或薄纱拼接。
- 肩部轻露，吊带或细肩带结构。
- 裙摆蓬松，带羽毛或碎纱边缘。
- 上身有蓝白花纹或浅蓝渐变。

服装气质：像花仙子的轻纱礼服，不是日常裙，也不是厚重婚纱。要轻、薄、梦幻、会被光线穿透。

避免：现代 T 恤、牛仔、硬质制服、强烈黑色服装、厚重礼服、过度暴露或低俗风格。

## 5. 灯光与摄影语言

### 5.1 光线方向

画面主要使用强烈的侧逆光、窗光或棚灯模拟阳光。光线从画面左上、右上或后方穿过纱幕、花束和头发，产生明显边缘光。

典型光效：

- 头发边缘有银蓝色高光。
- 花瓣和纱幕局部过曝。
- 玻璃器皿出现闪亮反光。
- 人脸保持柔亮，不出现硬阴影。
- 背景较暗，主体被光包裹。

### 5.2 氛围处理

- 有轻微柔焦和朦胧滤镜。
- 高光偏梦幻，局部溢光。
- 景深浅，前景花朵虚化。
- 背景暗部有雾感，不完全清晰。
- 整体像一张精修写真，而不是手机随拍。

### 5.3 镜头语言

建议镜头感：

- 50mm / 85mm 人像镜头
- 大光圈 f/1.4 - f/2.8
- 浅景深
- 纵向 2:3 构图
- 近景、半身、中景混合
- 局部前景遮挡

## 6. 构图规律

### 6.1 常见构图

1. **近景头像 + 蝴蝶手势**  
   人物靠近镜头，手持蓝蝶，脸部占画面 40% 左右。前景花束在下方或右下角虚化。

2. **花丛包围式坐姿**  
   人物坐在花束和玻璃器皿之间，两侧蓝白花形成框景，身体略侧，手扶地或托腮。

3. **蝴蝶遮眼 / 手触脸颊**  
   手拿蝴蝶靠近眼睛或唇边，制造神秘感。

4. **粉紫变体近景**  
   紫色花海包围，粉紫蝴蝶停在头发和手指间，画面更甜、更柔。

5. **玻璃瓶与珍珠前景**  
   透明罐、珍珠链、花瓣在前景形成层次，主体位于中景。

### 6.2 画面层次

一张图至少要有三层：

- 前景：虚化花束、蝴蝶、玻璃瓶、珠链。
- 中景：人物、手势、服装、主要蝴蝶。
- 背景：暗木家具、纱幕、垂花、鸟笼、珍珠链。

如果只有人物和纯背景，就失去这套图的核心。

## 7. 姿势与表情

### 7.1 推荐姿势

- 坐在花束之间，一手撑地，一手托腮或拿蝴蝶。
- 侧坐，双腿自然弯曲，裙摆铺开。
- 上半身微微前倾，眼睛直视镜头。
- 手指轻捏蝴蝶，靠近嘴唇或脸侧。
- 低头看蝴蝶，眼神柔和。
- 回头看镜头，肩膀略转，头发形成曲线。
- 抱着玻璃罐或花束，身体被花和纱半遮挡。

### 7.2 表情方向

- 空灵凝视
- 轻微张唇
- 温柔低眉
- 柔弱但不悲伤
- 微微惊讶感
- 安静、梦游般的神情

避免：大笑、鬼脸、过度卖萌、强烈挑逗、夸张动态。

## 8. 单图拆解

### 图 1：近景手捧蓝蝶

- 构图：半身近景，人物在画面中央偏右，手捧蓝蝶靠近镜头。
- 重点：脸部水光、蓝蝶发饰、面颊蓝蝶贴纸、蓝白花束前景。
- 光线：强侧光照亮发丝和脸部，背景较暗。
- 氛围：清冷、脆弱、花仙感。

### 图 2：蓝花环绕坐姿

- 构图：中景坐姿，人物被左右花束包围。
- 重点：大量蓝花、透明纱幕、玻璃罐、珍珠链、蓝蝶装饰。
- 姿势：一手撑地，一手轻触下巴或花朵。
- 氛围：最完整的“蓝蝶花境”场景图。

### 图 3：花丛中正面坐姿

- 构图：纵向全身 / 七分身，人物坐在花艺装置中央。
- 重点：腿部自然弯曲，双手与蝴蝶互动，玻璃器皿和珠链制造细节。
- 光线：顶部和侧面有强高光，花朵形成前后景。
- 氛围：童话、繁复、装置感强。

### 图 4：侧身回望蓝蝶

- 构图：人物侧坐回望，肩部和长发形成流动线。
- 重点：侧脸、长卷发、手持蓝蝶、蓝花围绕。
- 氛围：更成熟、更安静，带一点回眸感。

### 图 5：紫色花境近景

- 构图：半身正面，人物手捧粉紫蝴蝶，紫花围绕。
- 重点：粉紫蝶、紫花、面颊亮片、透明花纹纱裙。
- 色彩：由蓝白切换为粉紫白，但仍保留梦幻柔光。
- 氛围：更甜、更柔、更像梦幻花园。

### 图 6：紫蝶低头侧脸

- 构图：近景，人物低头看蝴蝶，头发和花朵填满画面。
- 重点：粉紫蝶贴在发间、手指、嘴唇和脸颊妆容。
- 光线：暗部较多，主体局部被柔光打亮。
- 氛围：神秘、安静、微暗梦境。

### 图 7：抱玻璃罐近景

- 构图：半身近景，人物抱着透明玻璃罐，蝴蝶在罐口和发间。
- 重点：透明玻璃反光、粉紫花、白纱裙、长卷发。
- 氛围：精致、柔弱、像花房里的蝴蝶收藏者。

### 图 8：蓝紫混合花境

- 构图：近景，人物在紫花和白花之间，脸部为视觉中心。
- 重点：高光蝴蝶发饰、眼下蓝紫贴纸、水光唇、深色背景。
- 氛围：蓝紫混合的最终变体，颜色更浓，梦幻感更强。

## 13. 画面质量控制清单

生成或筛图时，优先检查以下项目：

1. 是否有明确的蓝蝶 / 紫蝶主题。
2. 是否有蓝白花束、透明纱幕、玻璃器皿、珍珠链等核心道具。
3. 背景是否为暗木复古空间，而不是普通白棚。
4. 人物是否为成年女性气质，避免幼态化。
5. 发型是否是自然蓬松长卷发，而不是短发或直发。
6. 脸颊是否有细小蝴蝶贴纸或亮片细节。
7. 服装是否轻纱、浅蓝白或粉紫白，并有花仙感。
8. 光线是否有明显侧逆光、柔焦和高光溢出。
9. 前景、中景、背景是否有层次。
10. 花朵和蝴蝶是否精致，不要变形成杂色团块。
11. 手部是否自然，捧蝴蝶或触脸动作不要畸形。
12. 画面是否保持高级写真质感，而不是廉价 cosplay 棚拍。

## 14. 推荐参数方向

### 14.1 构图比例

- 竖图：2:3、3:4、4:5 均可。
- 最推荐：2:3 竖构图，适合完整花艺和人物姿态。
- 近景头像可使用 4:5。

### 14.2 镜头建议

- 近景：85mm，f/1.4 - f/2。
- 中景：50mm 或 70mm，f/2 - f/2.8。
- 全身坐姿：50mm，适度保留环境。

### 14.3 光线建议

- 主光：左上或右上侧逆光。
- 辅光：柔和反光板补脸。
- 环境：暗木背景压暗，白纱和花朵局部提亮。
- 特效：轻微雾化、柔焦、高光 bloom。
