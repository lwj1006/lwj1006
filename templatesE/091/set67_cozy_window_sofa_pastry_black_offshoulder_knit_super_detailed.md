# SET 67 — 暖窗蓝沙发甜点篮黑色露肩针织室内写真｜超详细生成提示词 MD

> 用途：把本套参考图整理成可复用的“写真 / 图生图 / 角色替换 / 二次元改图”提示词。  
> 核心关键词：**室内蓝色沙发、暖窗逆光、木百叶窗、黑色露肩毛绒针织、甜点篮、叉子、小蛋糕、慵懒下午茶、柔光、胶片感、居家咖啡馆氛围**。  
> 安全与身份原则：参考图仅用于**姿势、构图、服装、场景、光线、色彩与氛围**。不要复刻现实人物身份、脸部特征、平台 UI、截图黑边或水印。最终人物应为原创成年角色。

---

## 1. 总体视觉概念

一组温暖、安静、带轻微慵懒感的室内生活写真。场景位于复古咖啡馆、民宿客厅、窗边休息区或暖色调居家空间。主体坐在深蓝色布艺沙发或扶手椅上，旁边有木质窗框、木百叶窗、深色木墙裙、窗帘、抱枕、针织毯与小木桌。画面中出现藤编托盘或藤编篮，里面放着小蛋糕、泡芙、马芬、炸面包球、甜点杯等下午茶甜点，人物用小叉子轻轻拿起甜点，或者捧着篮子低头观察。

主体穿黑色露肩毛绒针织上衣，整体偏柔软、温暖、居家休闲。画面重点不是强烈性感，而是**窗边暖光、深蓝沙发、黑色针织、浅金甜点、藤编篮、木质室内装饰**之间的质感对比。风格像手机随拍与精修写真之间的融合：有自然生活感，也有明确的人像构图和氛围设计。

## 3. 人物设定

### 3.1 年龄与气质

- 原创成年女性。
- 气质：安静、温柔、午后慵懒、轻微害羞、居家感。
- 表情可选：
  - 若有所思地看向甜点
  - 轻轻抬眼看镜头
  - 闭眼微笑闻甜点香气
  - 被拍到时自然浅笑
  - 侧脸看向窗外
  - 用手指轻触唇边，神情安静
- 整体应是生活方式写真、甜点主题写真、窗边人像，而不是低俗挑逗画面。
- 避免未成年感、儿童化比例、过度幼态表情。

### 3.2 发型

- 中长或长发，深棕、灰棕、黑棕、茶棕都可以。
- 发型具有蓬松卷度，带空气刘海或碎刘海。
- 可为低盘发、松散丸子头、低马尾、半扎发或蓬松侧扎。
- 头发应有自然凌乱感，几缕发丝垂在脸颊、颈侧和锁骨附近。
- 可有毛线发圈、灰色布艺发圈、小蝴蝶结或低调发饰。
- 窗光下发丝边缘有暖金色高光。

## 4. 服装设计

### 4.1 主服装：黑色露肩毛绒针织

- 黑色、深灰黑或炭黑色毛绒针织上衣。
- 质地厚实、柔软、有绒毛感或粗针织纹理。
- 领口为一字肩或自然滑落的露肩设计。
- 袖子偏长，袖口松软，可遮住部分手背。
- 上衣可以是短款，露出少量腰线，但整体保持完整、自然、生活写真感。
- 不要生成透明衣料、破损衣料或过度暴露设计。
- 肩部、锁骨处由窗光勾边，形成柔和高光。

### 4.2 下装与袜子

可选：

- 黑色高腰短裤。
- 黑色半裙。
- 黑色居家短裙。
- 黑色短裤配宽松毛线袜。
- 深色休闲裤，但画面以半身为主时可不强调。

袜子细节：

- 黑色堆堆袜或毛线袜。
- 适合坐在沙发上的居家氛围。
- 不需要高跟鞋或复杂鞋履。

### 4.3 配饰

可选但保持简单：

- 小耳钉。
- 细项链。
- 毛线发圈。
- 简单戒指。
- 不要复杂珠宝，不要现代奢侈品牌 logo。

## 5. 场景设定

### 5.1 室内空间

- 复古咖啡馆、民宿客厅、窗边休息区、下午茶房间。
- 深蓝色布艺沙发或扶手椅是核心背景。
- 沙发上可有：
  - 深蓝针织毯
  - 棕色波点抱枕
  - 白色或米色靠垫
  - 粗纹理布料
- 背景可以出现：
  - 木百叶窗
  - 木质窗框
  - 白色薄窗帘
  - 深色木墙裙
  - 浅米色墙面
  - 小木桌或茶几
  - 暖色阳光照进室内
- 画面整体要有复古、温暖、木质、下午茶氛围。

### 5.2 甜点道具

必须或强烈建议出现：

- 藤编篮、藤编托盘或圆形竹编盘。
- 小蛋糕、泡芙、马芬、炸面包球、奶油杯、甜点杯等。
- 小叉子或甜点叉。
- 木桌、咖啡杯、餐巾、白色小盘。

甜点视觉：

- 颜色偏金黄、焦糖、奶油白、椰蓉白、橙黄。
- 甜点表面有真实烘焙纹理。
- 可以有一颗甜点被叉子举起。
- 可以有人物捧着篮子或把甜点靠近脸颊闻香味。
- 避免食物变形、塑料感或无法识别。

### 5.3 背景物件

可选：

- 木百叶窗左侧竖向排列。
- 窗口过曝白光。
- 深蓝沙发靠背。
- 木墙裙横向线条。
- 波点抱枕。
- 小木茶几。
- 白色杯子。
- 纸巾或布餐巾。
- 少量零食包装可作为生活感背景，但不要出现可读商标。

## 6. 光线与色彩

### 6.1 光线

- 主要光源为窗边自然光。
- 可以是强烈暖窗逆光，背景窗户轻微过曝。
- 人物脸部保留柔和阴影，不要完全死黑。
- 头发边缘、肩膀、锁骨、甜点边缘有金色轮廓光。
- 沙发与人物正面可有柔和反光补光。
- 适合出现轻微光晕、胶片噪点、暖色空气感。

### 6.2 色彩

主色：

- 黑色 / 炭黑：针织上衣与下装。
- 深蓝：沙发、针织毯。
- 暖木色：窗框、百叶窗、墙裙、小桌。
- 金黄 / 焦糖色：甜点。
- 米白 / 奶油白：墙面、窗帘、杯子。
- 暖白：窗光。

色彩情绪：

- 温暖、复古、午后、安静、居家。
- 深色服装与深蓝沙发形成沉稳底色。
- 甜点的金黄色作为画面暖色锚点。
- 不要变成冷灰阴暗棚拍。
- 不要过度磨皮导致人物像塑料娃娃。

## 7. 镜头语言

### 7.1 推荐镜头

- 35mm：表现沙发、窗户、木桌和甜点整体关系。
- 50mm：半身坐姿，突出人物、甜点篮、针织质感。
- 85mm：近景人像，表现眼神、发丝、甜点、窗边柔光。
- 手机随拍感：轻微高光溢出、自然构图、生活化姿态。
- 胶片感：柔和颗粒、低对比阴影、暖色窗光。

### 7.2 景深

- 人物脸部、手、甜点篮、叉子应清晰。
- 背景木百叶窗和窗帘可轻度虚化。
- 沙发纹理应保留，但不抢人物。
- 食物不能过度虚化到无法识别。
- 近景中甜点与手可以作为前景焦点，人物脸保持可读。

### 7.3 构图比例

- 竖图 2:3、3:4 或 9:16。
- 可以是截图感竖构图，但最终画面不要保留黑边和 UI。
- 半身近景最适合本套氛围。
- 可做轻微俯拍，表现人物坐在沙发上的姿态。
- 可做侧脸逆光，表现肩颈线和窗光。
