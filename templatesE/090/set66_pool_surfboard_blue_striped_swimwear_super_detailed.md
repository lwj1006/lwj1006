# SET 66 — 泳池冲浪板蓝白条纹泳装写真｜超详细生成提示词 MD

> 用途：把本套参考图整理成可复用的“写真 / 图生图 / 角色替换 / 二次元改图”提示词。  
> 核心关键词：**户外泳池、蓝白条纹泳装、红橙色冲浪板、清澈蓝色池水、城市度假感、阳伞、藤编围栏、强日光、夏日运动写真、清爽活力**。  
> 安全与身份原则：参考图仅用于**姿势、构图、服装、场景、光线、色彩与氛围**。不要复刻现实人物身份、脸部特征、水印文字或平台 UI。最终人物应为原创成年角色。

## 1. 总体视觉概念

一组明亮、清爽、夏日感强烈的户外泳池写真。场景位于城市中的露天泳池或屋顶泳池区域，背景有浅蓝色池水、白色泳池边缘、黑白马赛克砖线、藤编围栏、黄色遮阳伞、粉色休闲椅、城市建筑与运动休闲设施。主体是一位原创成年女性，穿蓝白横条纹分体泳装，搭配白色绑带边缘，长发自然垂落或被风轻轻吹起，手持或倚靠一块醒目的红橙色冲浪板。

整体风格不是暗调性感棚拍，而是**阳光、清凉、运动、泳池、度假、明快、干净的夏日写真**。画面重点在蓝色池水、红橙冲浪板、蓝白泳装、白色池边、强日光高光与轻微水花之间的色彩对比。

## 3. 人物设定

### 3.1 年龄与气质

- 成年女性，清爽、自然、明亮。
- 气质：夏日运动感、轻松度假感、亲近镜头但不夸张。
- 表情：轻柔微笑、自然凝视、阳光下眯眼、低头浅笑、被水花溅到时闭眼微笑。
- 避免过度挑逗、低俗、夸张性感化表情。
- 避免未成年感、儿童化比例、校园未成年氛围。

### 3.2 发型

- 长发，黑色或深棕黑色。
- 发长至胸下或腰侧。
- 发丝自然垂落，部分被微风吹起。
- 可有轻微湿发感，但不要完全贴头皮。
- 池水边可有细碎发丝贴在脸颊、锁骨、肩部。
- 阳光下头发边缘有棕色高光。

可选发丝细节：

- 侧脸时头发沿背部自然下垂。
- 站在池边时发尾被风吹向一侧。
- 玩水时发丝有几缕湿润分束。
- 近景中手指轻轻拨发。

## 4. 服装设计

### 4.1 主泳装

- 蓝白横条纹分体泳装。
- 上装为三角形或运动感比基尼上衣。
- 主色为深海军蓝，带细密白色横条纹。
- 边缘和肩带为白色或浅色绑带。
- 下装同样为蓝白横条纹，边缘白色包边。
- 服装应完整、贴合、自然，保持运动泳装感。
- 不要生成透明、破损、过度暴露或不合身的服装。

### 4.2 配饰

可选：

- 金色小项链或蓝色小吊坠。
- 细手链、黑色或木珠手串。
- 简单耳饰。
- 指甲可为浅蓝色或白色，呼应泳池与泳装。
- 不需要复杂珠宝，避免喧宾夺主。

## 5. 场景设定

### 5.1 地点

- 户外泳池、城市露天泳池、屋顶泳池、度假泳池。
- 池水是清透亮蓝色或青蓝色。
- 池边是白色瓷砖，带黑色细条马赛克边线。
- 背景可以有：城市高楼、红砖建筑或蓝色建筑、黄色遮阳伞、粉色休闲椅、藤编围栏、金属泳池扶梯、远处模糊的泳池设备或救生设施。

### 5.2 关键道具

必须或强烈建议出现：

- 红色、橙红色或亮橙色冲浪板 / 浮板。
- 蓝色泳池水面。
- 白色泳池边缘瓷砖。
- 黑白马赛克泳池边线。

可选道具：

- 黄色遮阳伞。
- 粉色金属椅。
- 藤编围栏。
- 金属泳池扶梯。
- 少量水花、水滴、反光涟漪。

### 5.3 冲浪板细节

- 冲浪板颜色鲜艳：红色、橙红或珊瑚红。
- 板身可有白色简洁图形或抽象字母，但不要出现真实品牌文字。
- 板面有轻微划痕、橡胶防滑垫或纹理区域。
- 冲浪板可以横向放在人物身后、竖立靠在椅子旁、斜靠在泳池边、被人物一手扶住，或作为大色块背景切入画面。

## 6. 光线与色彩

### 6.1 光线

- 明亮户外日光。
- 高曝光但不死白。
- 肩膀、头发、脸颊、手臂、泳池水面有明显阳光高光。
- 阴影边缘较硬，但人物脸部仍保持柔和。
- 可有遮阳伞投下的浅色阴影。
- 池水反光带来轻微蓝色补光。

### 6.2 色彩

主色：

- 青蓝 / 天蓝：泳池水。
- 深蓝 + 白色：条纹泳装。
- 红橙 / 珊瑚红：冲浪板。
- 白色：池边瓷砖。
- 黄色：遮阳伞。
- 浅粉：椅子。
- 城市灰、砖红：背景建筑。

色彩情绪：

- 清爽、高亮、夏日、度假。
- 池水颜色要干净透明，不要浑浊。
- 红橙冲浪板作为强烈视觉锚点。
- 皮肤色调自然，不要过度磨皮或蜡像感。
- 避免色彩过饱和导致廉价感。

## 7. 镜头语言

### 7.1 推荐镜头

- 35mm：环境写真，能表现泳池、冲浪板、城市背景。
- 50mm：半身与近景，突出人物与泳装纹理。
- 85mm：人像压缩感，突出脸部、发丝与池水虚化。
- 高角度俯拍：表现泳池曲线、池边瓷砖、人物坐姿或站在水中。
- 低角度或平视：表现冲浪板的大色块与人物站姿。

### 7.2 景深

- 人物脸部、眼睛、泳装与冲浪板应清晰。
- 池水背景可轻度虚化。
- 城市建筑和远处人物必须虚化，不要抢主体。
- 水花可有部分凝固瞬间，也可以轻微运动模糊。

### 7.3 画质

- 高质量写真感。
- 皮肤真实自然，不要塑料质感。
- 泳池水面要有真实波纹和反射。
- 瓷砖边线要整齐，避免变形错位。
- 手指、脚趾、肩带、冲浪板边缘要干净准确。
