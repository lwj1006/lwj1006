## 1. 总体视觉定位

这一套图的气质不是浓重棚拍，也不是强剧情写真，而是**夏日午后、半室内半庭院、自然光穿过玻璃窗形成强烈明暗对比的清透人像写真**。画面里的人物穿浅色、象牙白、奶油白系衣装，背景多为深色门窗、阴影廊道、绿植虚化和室内玻璃反光。整体观感是：

- 明亮但不刺眼，人物皮肤被阳光打亮，背景则压暗。
- 服装以白色、米白、浅蓝灰花纹为主，和夏日柠檬饮品形成清爽感。

- 构图偏近景和半身，人物眼神自然看向镜头或轻微侧望。
- 情绪是安静、温柔、干净、轻松，不是强烈性感，也不是夸张可爱。

最终图像应呈现**白裙长发女性在玻璃窗边、庭院入口或咖啡廊道里的夏日清爽写真**，重点是光、发丝、肤感、白衣层次和浅柠檬饮品的透明质感。

## 2. 参考图视觉 DNA

### 2.1 场景 DNA

场景主要围绕以下元素展开：

1. **深色玻璃门窗**  
   黑色或深墨绿色窗框，玻璃有室外树影反光。背景暗，人物被阳光打亮，形成高反差。

2. **室内外交界处**  
   像咖啡馆门口、庭院廊道、玻璃房入口、老式洋馆阳台或阴凉门廊。画面既有室内阴影，也有室外绿植光斑。

3. **自然绿植虚化**  
   远处有树叶、庭院、夏日绿色背景，使用浅景深让绿植成为柔和散景。

4. **白色桌椅与饮品**  
   有白色铁艺椅、户外小圆桌、玻璃杯、柠檬片、吸管、淡黄色饮料。道具少而精，不要堆满杂物。

5. **老建筑质感**  
   可出现砖墙、木柱、深色门框、老窗扣、白色墙裙、阴影走廊，增强真实生活气息。

### 2.2 光线 DNA

这一套最重要的是光线：

- 主光为夏日自然阳光，从侧前方或侧后方打入。
- 背景通常暗，人物脸部和肩部有高光。
- 发丝边缘出现强烈逆光亮边，尤其是头顶和发梢。
- 皮肤高光偏柔，不要油腻，不要塑料磨皮。
- 可有树叶投影、窗框投影、斑驳光点。
- 高光可以略过曝，但脸部五官必须保留细节。
- 画面要有空气感和光雾感，但不要变成雾蒙蒙糊片。

### 2.3 色彩 DNA

主色调：

- 象牙白 / 奶油白 / 米白
- 深墨绿 / 黑色玻璃反光
- 夏日叶绿色
- 柠檬淡黄
- 少量浅蓝灰花纹
- 皮肤偏暖白，唇色自然珊瑚粉

色彩关系：

- 人物服装很浅，背景很暗，形成干净的明暗分离。
- 绿色背景只作为辅助，不要抢人物。
- 柠檬饮品是视觉小亮点，颜色应透明、清爽、淡黄绿。
- 不要高饱和滤镜，不要橙黄色过度胶片化。

## 3. 人物设定

### 3.1 人物气质

人物应是**成年女性**，气质清爽、温柔、自然、轻盈。她不是强烈摆拍的商业模特，而像在夏日午后被朋友或摄影师自然捕捉到的状态。

关键词：

- 温柔
- 清透
- 安静
- 亲近
- 自然
- 夏日感
- 轻微微笑
- 眼神干净
- 不夸张卖萌

### 3.2 五官与表情

参考情绪：

- 轻轻看向镜头，嘴角微微上扬。
- 头部略微倾斜，眼神柔和。
- 偶尔侧脸回望，肩膀朝前，脸回头看镜头。
- 可有手托脸、手扶头发、手拿饮品、轻靠桌边。
- 表情不要过度甜腻，不要夸张张嘴大笑。

推荐表情：

- 柔和直视镜头
- 轻微微笑
- 安静侧望
- 低头浅笑
- 回眸凝视
- 眯眼迎光但五官清晰

避免：

- 夸张媚态
- 过度嘟嘴
- 过度网红脸
- 过度幼态化
- 表情僵硬
- 眼睛巨大失真

### 3.3 发型

核心发型：

- 长黑棕发或深茶色长发。
- 发量自然充足，长度到胸下或腰附近。
- 中分或偏分，刘海轻薄自然。
- 发丝被风吹起，局部飞散。
- 逆光下发丝边缘有明显高光。

可选变化：

- 全披肩长发。
- 一侧头发自然别到耳后。
- 手指轻轻拨发。
- 头发被风从一侧吹起。
- 坐姿时头发自然垂落在肩前。

避免：

- 过度整齐的假发感。
- 头发结成大块，没有细发丝。
- 发丝边缘像噪点或断裂线。
- 颜色过红、过紫、过蓝。

## 5. 道具设定

### 5.1 核心道具：柠檬饮品

玻璃杯中的淡黄色柠檬饮品是这套图的标志性道具之一。

道具细节：

- 高透明玻璃杯。
- 淡黄色柠檬水或气泡饮。
- 杯中可见柠檬片、青柠片、冰块、薄荷叶。
- 黑色或透明吸管。
- 杯壁有轻微冷凝水。
- 阳光穿过杯子形成淡黄色透光。

动作：

- 单手举杯对镜头微笑。
- 坐在桌边，用吸管轻轻搅拌。
- 手托腮，另一只手扶杯子。
- 站在门口，把杯子递向镜头。
- 杯子放在桌边作为前景虚化。

避免：

- 饮品颜色过浓，像橙汁或荧光液体。
- 杯子变形。
- 吸管多到混乱。
- 柠檬片像硬币或塑料片。

### 5.2 辅助道具

可选但不要过多：

- 白色铁艺椅
- 小圆桌
- 简洁项链
- 珍珠耳坠或小耳环
- 细手链
- 白色帘布
- 植物阴影
- 玻璃窗反光

避免：

- 水印、Logo、账号 ID。
- 杂乱餐具。
- 过多饮料杯。
- 大量文字牌。
- 现代广告牌抢镜。

8. **半身正面柔光**

## 13. 镜头与参数建议

### 13.1 摄影复刻参数

- 镜头：50mm / 85mm
- 光圈：f/1.4 - f/2.8
- 快门：1/500s - 1/2000s，保留阳光高光和发丝瞬间
- ISO：100 - 400
- 白平衡：日光 5200K - 6000K
- 对焦：眼睛优先，近景对焦在眼睛，杯子作为辅助前景
- 曝光：脸部不过曝，允许白衣局部高光轻微溢出

### 13.2 后期建议

- 保留皮肤细节，不要磨成塑料。
- 高光偏奶白，阴影偏深绿或黑色。
- 轻微降低背景饱和度，让人物和白衣突出。
- 增强发丝边缘高光，但不要锐化过度。
- 柠檬饮品提高透明感和清爽黄色。
- 整体色温略暖，但不要橙黄过头。

## 15. 质量检查清单

生成或拍摄完成后逐项检查：

- [ ] 背景是否是深色玻璃窗、廊道、庭院绿植，而不是杂乱商业街？
- [ ] 人物是否有自然长发和逆光发丝？
- [ ] 白色服装是否有布料层次，而不是一片死白？
- [ ] 脸部是否清晰、眼睛是否有神？
- [ ] 皮肤是否真实细腻，没有塑料磨皮？
- [ ] 柠檬饮品是否透明、有柠檬片、冰块和薄荷？
- [ ] 手指是否自然，没有多指、断指、融合？
- [ ] 背景是否压暗，人物是否被阳光分离出来？
- [ ] 是否去除水印、账号 ID、平台 UI 和文字？
- [ ] 整体情绪是否清爽、温柔、安静，而不是过度性感或过度幼态？
