# Set 20 — 金鱼水箱 / 暖木室内 / 湿发植物感 超详细图像拆解 MD

> 用途：整理这套 7 张参考图的视觉系统、构图方法、场景道具、光线逻辑、动作库与可复用提示词。  
> 说明：这是 **图像分析 + 生成提示词文档**，不是画图任务。  
> 核心方向：室内暖光、透明水箱、橙色金鱼、湿发少女、植物藤蔓、木质空间、复古胶片感。

---

## 0. 总体概念

这一套的核心不是“泳池水感”，而是更私密、更复古、更有叙事性的 **室内水箱写真**。

画面中的主轴是：

```text
透明方形水箱 + 橙色金鱼 + 暖色室内日光 + 木质老房间 + 湿润黑发 + 植物藤蔓 + 草莓道具
```

它的氛围介于：

```text
复古日系写真 / 水族箱幻想 / 暖木植物房 / 午后私房光影 / 胶片颗粒人像
```

整套图的情绪不是明快甜美，而是：

```text
安静、潮湿、困倦、微热、贴近、迷离、带一点水族箱式隔绝感
```

人物与水箱之间存在强烈的“隔着透明介质观看”的关系。  
水箱不只是道具，而是整套图最重要的视觉装置。

# 2. 色彩系统

## 2.1 主色

```text
warm amber, dark wood brown, deep green, orange goldfish, soft cream white, muted blue-purple, strawberry red
```

中文：

```text
暖琥珀色，深木棕，深绿色，橙色金鱼，柔奶白，低饱和蓝紫，草莓红
```

## 2.2 色彩比例

大致比例：

```text
深木棕 / 暖室内色：30%
绿色植物：20%
人物肤色与白色衣物：20%
水箱透明灰蓝：15%
橙色金鱼：8%
草莓红：4%
暗蓝紫服装：3%
```

## 2.3 色彩逻辑

这套的色彩非常有层次：

- **暖木棕**：负责复古、室内、怀旧
- **植物绿**：负责潮湿、生命感、自然感
- **金鱼橙**：负责视觉跳点
- **草莓红**：作为金鱼橙之外的第二暖色点
- **玻璃水箱的青灰透明感**：提供水感和隔离感
- **白色衣物 / 蓝紫碎花衣物**：让人物从深色背景中浮出来

重要的是，金鱼的橙色必须很醒目，否则主题会弱。

# 4. 核心道具系统

## 4.1 透明方形水箱

这是整套最重要的道具。

关键词：

```text
large rectangular glass aquarium, clear acrylic fish tank, transparent water box, water surface line, glass reflection, refraction
```

中文：

```text
大型长方形玻璃水箱，透明亚克力鱼缸，透明水盒，水位线，玻璃反光，水面折射
```

水箱的作用：

1. 建立水族箱主题  
2. 用玻璃边缘切割画面  
3. 用水面线遮挡或分割人物脸部  
4. 产生折射和变形  
5. 让金鱼在人物前方游动，制造层次  

## 4.2 金鱼

关键词：

```text
orange goldfish, white-and-orange goldfish, floating goldfish, blurred foreground fish, fish silhouettes
```

中文：

```text
橙色金鱼，橙白金鱼，游动金鱼，前景虚化金鱼，金鱼剪影
```

金鱼必须具备：

- 明亮橙色
- 可见鱼尾
- 多条游动
- 有前景虚化和中景清晰的层次
- 与人物脸部形成“隔水对望”的关系

## 4.3 草莓

部分图中出现白盘草莓、罐装草莓：

```text
plate of strawberries, glass jar with strawberries, red fruit accents
```

中文：

```text
白盘草莓，玻璃罐草莓，红色水果点缀
```

草莓的作用是增加生活感和红色视觉点。  
它不应该抢过金鱼主题，只能作为辅助道具。

## 4.4 植物藤蔓

关键词：

```text
green vines, hanging leaves, foreground foliage, soft leaf shadows
```

中文：

```text
绿色藤蔓，垂落叶片，前景叶子，柔和叶影
```

植物经常位于前景，制造遮挡、纵深、自然感。

# 7. 光线系统

## 7.1 主光

```text
warm afternoon sunlight, low-angle window light, golden light streaks, dappled plant shadows
```

中文：

```text
暖色午后日光，低角度窗光，金色光带，植物斑驳阴影
```

## 7.2 光线特征

这一套的光线非常关键，不是均匀柔光，而是：

- 局部强光
- 局部暗影
- 光线穿过窗、植物、水箱
- 暖色反射明显
- 鱼缸边缘产生高光
- 水面形成一道横向光带

## 7.3 胶片颗粒

画面明显有胶片质感：

```text
soft film grain, nostalgic color grading, slightly underexposed shadows, warm highlights
```

中文：

```text
柔和胶片颗粒，怀旧调色，阴影略欠曝，暖色高光
```

这套不要过度干净。  
需要保留颗粒、暗部、偏色和轻微模糊。

# 8. 构图系统

## 8.1 水箱框架构图

大量画面使用水箱作为画中框：

```text
glass aquarium as foreground frame, waterline crossing the face, fish between subject and camera
```

中文：

```text
玻璃水箱作为前景框架，水位线横切脸部，金鱼位于人物与镜头之间
```

这类构图的重点：

- 水箱边缘形成几何矩形
- 人物被水箱局部遮挡
- 水位线形成横向分割
- 金鱼作为动态前景
- 玻璃反光制造真实感

## 8.2 贴近地面的构图

人物经常躺在地面、毯子或榻榻米上：

```text
low angle floor portrait, lying beside aquarium, close-to-ground composition
```

中文：

```text
低角度地面人像，躺在鱼缸旁，贴近地面的构图
```

这种视角带来亲密感和困倦感。

## 8.3 极近景构图

近景中脸部占据巨大比例，金鱼、水面、玻璃边缘在前景虚化：

```text
extreme close-up through glass, face behind aquarium, blurred goldfish foreground
```

中文：

```text
隔着玻璃的极近景，脸在鱼缸后方，前景金鱼虚化
```

## 8.4 前景遮挡

植物、鱼缸、金鱼、水面、书页都可以作为前景遮挡：

```text
foreground leaves, blurred fish, glass edge, water reflection, book page
```

中文：

```text
前景叶片，虚化金鱼，玻璃边缘，水面反光，书页
```

# 9. Image 01 — 大水箱卧躺开场图

## 9.1 图像概述

人物躺在厚针织毯或床铺旁，透明方形水箱位于画面中心，橙色金鱼在水中游动。人物半躺在水箱后方，手抱白色花朵，前景有一盘草莓。背景是深木墙、老窗和植物藤蔓。

## 9.2 构图分析

- 水箱居中，是主视觉框架。
- 人物横向躺在水箱后方，身体从左侧延伸到右侧。
- 金鱼在水箱前景形成橙色动态点。
- 草莓盘位于画面下方，提供红色辅助点。
- 后方木窗和植物提供室内复古气氛。
- 画面有强烈的“隔着鱼缸看人”的叙事。

## 9.3 光线分析

- 暖色日光从左下或侧方照入。
- 水箱边缘被高光描边。
- 人物脸部局部被暖光照亮。
- 深木背景压暗，突出水箱透明感。
