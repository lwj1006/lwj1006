# 焚诀 3.0 第一轮出图反馈：角色传播人格命中率 Review

## 当前结论

本轮 V3 方向是正确的，但命中率还不稳定。

已经能产出不错的图，说明：

```text
社交传播型二次元方向可以成立。
```

但大部分图仍然一般，主要问题不是画质，而是：

```text
角色差异不足
传播符号过载
甜美模板化
南宫羽 / 爱芮边界模糊
丹容易被成熟化
```

下一轮重点不应该继续堆更多“好看元素”，而应该：

```text
减少通用传播模板，
强化每个角色独有的传播人格。
```

---

- 大脸清晰

- 天空高亮

- 机械翅膀保留

```text
不是普通自拍，

```

这张说明南宫羽的传播方向可以成立：

```text
控制感
轻挑衅
小恶魔队长
viewer 被她调度
```

# 二、本轮主要问题

## 1. 传播符号过载

本轮很多图反复出现：

- 光环
- 爱心
- UI
- 翅膀
- 星星
- 手机
- 耳机
- 粉紫霓虹

这些元素确实有传播性，但同时出现太多后，会变成：

```text
V3 通用模板
```

而不是：

```text
角色专属传播人格。
```

下一轮需要限制：

```text
每张图最多只允许 1 个 primary hook symbol，
再配 1 个 secondary support symbol。
```

例如：

### 南宫羽

主符号：

- 科技光环
- 节奏 UI
- 猫发夹

辅助符号：

- 机械小翅膀

---

### 爱芮

主符号：

- 爱心环
- 麦克风
- 直播 UI

辅助符号：

- 粉色机械翅膀

---

### 丹

主符号：

- 枕头梦境
- 羽毛
- 白银光环

辅助符号：

- 星图
- 透明书本

---

## 2. 南宫羽甜妹化

南宫羽现在好看，但部分图已经偏成：

```text
粉黑可爱主播
```

而不是：

```text
天才队长
控场者
小恶魔调度者
```

南宫羽可以有亲密感，但不能太软。

她的表情应该更多是：

- 轻挑衅
- 坏笑
- 冷静看穿 viewer
- 命令感
- “你已经进入我的节奏”

不应该过多变成：

- 可爱
- 害羞
- 甜笑
- 普通自拍

---

## 3. 爱芮和南宫羽边界模糊

目前两人都在使用：

- 粉黑
- 爱心
- 光环
- 翅膀
- UI
- 近景互动

这会导致角色区分变弱。

下一轮必须明确切分：

### 南宫羽

```text
控制感
节奏感
小恶魔队长
猫系压迫
黑粉科技
```

她的 viewer relationship 是：

```text
她调度你。
```

---

### 爱芮

```text
偶像营业
直播互动
高能甜酷
粉丝服务
恋爱信号
```

她的 viewer relationship 是：

```text
她扑向你。
```

这两个角色的传播逻辑不能混在一起。

---

## 4. 丹容易被成熟化

白毛月亮图视觉质量很高，但胸部强调和成熟感偏强。

如果这是丹方向，需要谨慎。

丹目前最适合：

```text
梦境亲密感
安静收藏感
浅粉白银
不强营业
不强性感
```

丹不适合走：

```text
成熟御姐圣女
```

否则会偏离她原本：

```text
浅粉短发
安静温柔
略淡漠
未来圣女感
```

的角色定位。

# 三、下一轮修改重点

## 1. 增加角色传播差异约束

不要只写通用：

```text
viewer interaction
thumbnail hook
```

而要明确：

```text
这个角色如何互动
这个角色不该如何互动
```

建议定义：

```text
南宫羽：互动 = 控制 viewer
爱芮：互动 = 主动营业 viewer
千夏：互动 = 小心靠近 viewer
丹：互动 = 安静凝视 viewer
```

这是下一轮最关键的修改。

---

## 2. 限制传播符号数量

新增规则：

```text
每张图只能有一个 primary hook symbol。
其他符号必须降级为背景或小装饰。
```

目的：

- 降低画面过满
- 避免 AI 套模板
- 强化主视觉钩子
- 提高缩略图清晰度

---

## 3. 增加角色误读惩罚

建议加入比普通 negative prompt 更高优先级的误读压制：

```text
南宫羽禁止变成普通粉黑主播。
爱芮禁止变成普通粉毛偶像。
丹禁止变成成熟大胸圣女。
千夏禁止变成普通薄荷 JK。
```

这类误读惩罚应该进入角色传播人格 profile。

---

## 4. Thumbnail First 继续保留，但不要只追求大脸

本轮部分图已经在向：

```text
大脸 + 光环 + UI + 爱心
```

收敛。

下一轮 Thumbnail First 应该拆成不同类型：

- 大脸型
- 半身型
- 姿态型
- 色块型
- 符号型

不同角色、不同 plan 应该匹配不同缩略图策略。

不要让所有角色都变成大脸自拍。

---

# 五、总判断

这轮不是失败，而是 V3 第一轮方向验证。

已经证明：

```text
社交传播型二次元方向能出好图。
```

但还需要解决：

```text
角色差异不足
符号过载
甜美模板化
南宫羽 / 爱芮边界模糊
丹容易被成熟化
```

下一轮核心任务：

```text
不要继续堆好看元素。
要建立角色专属传播人格约束。
```

最终目标：

```text
每个角色都能以自己的方式吸引 viewer，
而不是共享同一套高流量模板。
```
