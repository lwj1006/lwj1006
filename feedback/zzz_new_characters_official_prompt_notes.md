# 1. 叶瞬光

## 官方信息摘要

- 中文名：叶瞬光
- 所属：云岿山
- 中文 CV：陶典
- 官方角色页核心语气：温柔、可靠、有师姐感，会主动照顾新徒弟。
- 角色关系：与仪玄、潘引壶、橘福福同属云岿山语境。
- 官方叙事关键词：师姐、剑、因果、承担、砥砺、保护他人。
- 战斗 / 调频信息：官方 2.5 限时频段中标注为限定 S 级代理人，定位为「叶瞬光（凛刃·强攻）」。
- 官方版本信息：2.5 版本中作为“首位双形态代理人-虚狩「叶瞬光」”登场。

## 官方语气转译

叶瞬光不是单纯冷面剑客。她的核心应该是：

```text
温柔师姐 + 执剑强者 + 承担型保护者 + 云岿山修行者
```

她的传播人格不应只做“酷”。更适合做成：

```text
外表清亮、气质温柔，画面里带一点剑意和命运感；
动作不夸张，但有明确的护人、回身、拔剑、垂眸守望气质。
```

## 视觉锚点建议

必须保留：

- 云岿山 / 中式修行者气质
- 剑、剑光、剑穗、符纹、山风、云气等元素
- 温柔师姐感，不要做成纯冷酷杀手
- 动作可安静，但气场要稳

适合强化：

- 清晨山门
- 云雾台阶
- 竹影 / 药铺 / 山市
- 剑光像月色或晨光一样划过画面
- 一手护住身后、一手持剑

## Fenjue 3.0 提示词基准

```text
叶瞬光，《绝区零》云岿山代理人，温柔可靠的师姐型执剑少女。角色气质是清亮、沉稳、护人、带一点命运感的强者，不是冷酷杀手。画面应保留云岿山修行者气质、剑、剑光、符纹、山风、云气或中式门派元素。她的动作可以是回身护人、垂眸收剑、晨雾中拔剑、山门前安静站立，重点是温柔师姐感和执剑承担感。社交平台传播方向：清澈、可靠、带幻想感的剑修少女，缩略图中必须能读出“云岿山 + 剑 + 温柔师姐”。
```

## 可用场景方向

```text
山门晨雾 / 云岿山台阶 / 竹影练剑 / 药铺门口 / 雨后石阶 / 月下剑光 / 师姐回身保护 / 山市买菜后的日常瞬间
```

# 2. 「席德」

## 官方信息摘要

- 中文名：「席德」
- 官方写法：带引号的「席德」
- 关键词：绳匠是“同类”、四叶草和油菜花、老席德、改造、隐身功能、机械 / 改装 / 童真逻辑。
- 所属语境：奥波勒斯小队相关内容中出现，官方壁纸文案称“奥波勒斯小队的大家可靠又温暖”。
- 战斗 / 版本信息：2.2 版本更新说明中标注为 S 级代理人「席德」（强攻·电），能造成大量电属性伤害，并可与其他强攻特性代理人配合。
- 代理人秘闻：官方说明中，「席德」的代理人秘闻为「花之谷的芙罗拉」。

## 官方语气转译

「席德」的核心不是普通机械少女，也不是单纯军武角色。她应该是：

```text
天真危险感 + 机械改造癖 + 与“老席德”的共生记忆 + 电属性强攻
```

她的语气中有一种“不按常识理解世界”的童真：

```text
她认真地说出很离谱的改造方案，
把机械、花、同类、隐身功能这些东西混在一起，
既可爱又有一点危险。
```

## 视觉锚点建议

必须保留：

- 机械 / 改装 / 机体零件
- 电属性 / 电弧 / 蓝紫电光 / 电路纹
- “老席德”或大型机械伙伴的存在感
- 天真但危险的表情逻辑
- 花朵、四叶草、油菜花等柔软符号可以和机械形成反差

适合强化：

- 机库角落
- 驾驶舱一隅
- 机械手臂旁边的小花
- 电火花照亮脸部
- 她把危险武器当玩具一样认真展示

## Fenjue 3.0 提示词基准

```text
「席德」，《绝区零》S级电属性强攻代理人，带有天真危险感的机械改造少女。角色核心是机械、改造、老席德、电弧、花朵和“不按常识理解世界”的童真逻辑。画面应保留电属性蓝紫光、机械零件、驾驶舱或机库角落、被她改造过的大型机械伙伴痕迹。她的表情可以很纯真，动作却在展示危险机械装置，形成可爱与危险并存的反差。社交平台传播方向：电光机械少女 + 花朵反差 + 天真危险感，缩略图中必须能读出“机械改造 + 电光 + 席德式童真”。
```

## 可用场景方向

```text
机库花园 / 驾驶舱一隅 / 电路维修台 / 大型机械肩膀上 / 零件堆里的四叶草 / 蓝紫电光实验室 / 老席德残影旁边 / 机械手心开花
```

# 3. 橘福福

## 官方信息摘要

- 中文名：橘福福
- 所属：云岿山
- 中文 CV：谢莹
- 角色定位：S 级代理人「橘福福（击破·火）」
- 官方版本信息：2.0 版本更新说明中说明，橘福福是兼具后台失衡能力与辅助能力的击破代理人。
- 官方活动 / 秘闻：橘福福的代理人秘闻为「《猛虎伏魔传！》」。
- 官方语境关键词：虎、虎威、山中清修、师姐、云岿山、猛虎伏魔。

## 官方语气转译

橘福福不是单纯猫系可爱。她是：

```text
虎系元气师姐 + 云岿山武修 + 火属性击破 + 猛虎伏魔感
```

她的画面最好有“热闹、冲劲、虎虎生风”的动势，但不能失去少女感和可爱度。

适合的传播人格：

```text
像会大声招呼你去吃饭、下一秒又能冲出去伏魔的元气虎系少女。
```

## 视觉锚点建议

必须保留：

- 虎系特征 / 虎纹 / 虎耳或虎尾气质
- 火属性、暖色冲击、拳脚或近身战斗感
- 云岿山门派感
- 「虎威」相关机械虎球 / 虎形装置 / 伏魔道具感
- 元气、热情、师姐感

适合强化：

- 石阶上冲刺
- 灯笼火光
- 庙会 / 山门 / 练武场
- 虎形火焰剪影
- 她挥拳或跃起时，火光和虎纹形成大轮廓

## Fenjue 3.0 提示词基准

```text
橘福福，《绝区零》云岿山S级火属性击破代理人，虎系元气师姐。角色核心是热情、冲劲、虎虎生风、云岿山武修和猛虎伏魔感。画面应保留虎系元素、火属性暖光、近身战斗动势、虎威或虎形机械装置、山门或练武场气质。她不是普通猫系少女，而是明亮、可爱、能打、像会拉着你一起去吃饭又马上冲出去伏魔的虎系师姐。社交平台传播方向：火光虎纹 + 元气师姐 + 伏魔动作，缩略图中必须能读出“虎 + 火 + 云岿山”。
```

## 可用场景方向

```text
山门练武场 / 灯笼庙会 / 石阶跃起 / 火光伏魔 / 早市买点心 / 虎威暴走小剧场 / 云岿山食堂 / 红色符纸与虎纹火焰
```
