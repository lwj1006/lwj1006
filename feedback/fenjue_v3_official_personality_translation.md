# 一、焚诀 3.0 的新原则

## 1. 不再凭空做“传播人格”

之前的方向：

```text
角色视觉空气
+
社交平台传播性
+
Pixiv 二次元幻想感
```

是对的。

但下一步不能只靠：

```text
自拍感
偶像感
恋爱感
神性
夏日空气
```

这些通用词。

否则角色会变成：

```text
套着角色皮的 generic 二次元 AI 图
```

焚诀 3.0 下一阶段必须做的是：

```text
官方人格
↓
二次元传播转译
↓
prompt profile
↓
plan/action/outfit/light/fantasy 的二次调制
```

---

## 2. “官方人格”不是限制，而是传播钩子的来源

《绝区零》的角色塑造很少是单纯属性标签。

它通常是：

```text
鲜明身份
+
强符号外观
+
舞台化口吻
+
阵营/职业语法
+
互动关系
+
可传播台词气质
```

所以焚诀 3.0 不能只提炼“好看女生”。

必须提炼：

```text
这个角色为什么会被记住？
她如何和 viewer 产生关系？
她的官方语气如何转译成社交平台停滑？
```

# 二、系统层级建议

建议新增一个角色传播人格层：

```python
CHARACTER_PROPAGATION_PROFILES = {
    "角色名": {
        "official_core": "...",
        "propagation_translation": "...",
        "viewer_relationship": "...",
        "thumbnail_strategy": "...",
        "fantasy_symbols": [...],
        "safe_sensuality": "...",
        "preferred_hooks": [...],
        "suppressed_misreads": [...],
    }
}
```

它不直接替代 plan/action，而是作为二次调制层。

旧逻辑：

```text
choose plan
choose action
生成 prompt
```

新逻辑：

```text
读取角色传播人格
↓
选择符合人格的 plan/action
↓
用传播人格修正镜头、情绪、幻想符号、缩略图重点
↓
生成 prompt
```

# 三、南宫羽 / Nangong Yu

## 1. 官方核心理解

官方资料里，南宫羽属于 Angels of Delusion 体系，并以天才、舞台、节奏、惩罚感、强控制力、表演性为明显关键词。官方内容中围绕她出现了 Agent Record、Character Demo、EP、新服装展示与主题壁纸，说明她不是单纯战斗角色，而是具备强视觉运营价值的舞台型角色。

她的官方语法不是：

```text
普通粉黑双马尾少女
```

而是：

```text
天才队长
+
舞台控制者
+
节奏/连击/调度感
+
带一点小恶魔压迫
+
知道自己处于画面中心
```

---

## 2. 传播人格转译

南宫羽的传播人格应定义为：

```text
playful controller idol
```

也就是：

```text
她不是向 viewer 撒娇，
而是在调度 viewer。
```

她的高流量点不是单纯可爱，而是：

- 她掌控画面
- 她主动设定关系
- 她有“你已经被她看穿”的感觉
- 她像在舞台、直播、游戏节奏里控制观众
- 她的表情可以有轻微坏笑、挑衅、戏谑

---

## 3. Viewer Relationship

适合：

- 轻挑衅对视
- 主导镜头
- 惩罚感台词氛围
- “你被她选中/锁定”的感觉
- 半近景，保留身体动作和双马尾识别
- 她主动靠近，但不做普通卖萌自拍

不适合：

- 害羞系女友
- 纯软妹
- 低幼萌妹
- 普通 JK 日常
- 无目的大脸自拍

---

- 猫发夹/发卡
- 科技光环或机械小翅膀
- 挑衅表情
- 粉黑高记忆色

缩略图钩子建议：

```text
脸 + 粉黑双马尾 + 坏笑 + 科技光环/小翅膀 + 一个大图形符号
```

---

## 5. 可用幻想符号

- 粉黑舞台光
- 机械小翅膀

```text
建立官方人格驱动的传播系统
```

```text

围绕角色本身运营的二次元传播系统
```
