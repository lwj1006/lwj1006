# art_direction_options.py 场景 / 服装主题追加方案

## 使用方式

把下面这段代码整体追加到 `art_direction_options.py` 文件末尾即可。

本追加块只影响：

- `ART_DIRECTION_PLANS`：新增场景方案。
- `OUTFIT_DIRECTIONS`：追加后重新生成服装主题列表。
- `PLAN_TAGS`：补齐新增场景的冷却标签。
- `CHARACTER_PLAN_WEIGHTS`：让不同角色有不同场景偏向。
- `CHARACTER_OUTFIT_VARIATIONS`：补充角色服装变体。
- `CHARACTER_PROPAGATION_PROFILES[...]["preferred_hooks"]`：让新增场景能吃到角色传播人格加权。

不会改：

- `art_direction_templates.py`
- `build_prompt(...)` / `prompt_for_art_direction(...)`
- `ACTION_STYLES`
- `CHARACTER_ACTION_WEIGHTS`
- `choose_art_plan(...)` / `choose_action_style(...)` 的逻辑
- `chatgpt_batch_pyautogui.py`
